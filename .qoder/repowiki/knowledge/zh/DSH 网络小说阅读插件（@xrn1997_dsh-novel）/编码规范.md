- 浏览器 client bundle 使用 tsdown 的 `neverBundle`/`alwaysBundle` 谓词显式划分平台模块与 npm 依赖，禁止 Node builtin 或跨插件值 import 进入最终包。
- CJS 客户端产物采用官方三段式 banner/intro/footer 包裹，id 固定为包名 `@xrn1997/dsh-novel`，作为 `window.__ModuleLoader__.load` 的 factory 被宿主加载。
- 测试用例按用途拆分为常规集、compat 回放集与 packaging-build 集，分别由主 vitest.config 与 vitest.compat.config.ts / vitest.pack.config.ts 隔离 include/exclude。
- 对外 HTTP API 路由与响应信封在 `src/shared/wire.ts` 统一定义，由 Node 半与浏览器半共享并通过契约测试逐条守卫。
- AI 助手工具统一以 `dshnovel_` 前缀注册，工具名集合由 `tests/tools/tools.test.ts` 钉死，避免与宿主生态其他插件重名。

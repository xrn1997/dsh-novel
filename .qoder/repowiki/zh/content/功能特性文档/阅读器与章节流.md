## 引言

## 项目结构

- `src/client/*`：浏览器侧的 React 视图、阅读会话、懒加载决策、进度保存与 UI 装配。

## 详细组件分析

### 章节正文求值：`chapter-content.ts`
该模块是“图文节点树 → 纯文本”的唯一投影。它同时服务于：
- 普通章节的 `text` 出口；
- TXT 导出；
- AI 工具输入；
- 阅读器的文字面展示。

核心规则如下：
- 块级元素形成换行边界；链接只输出内部文字，不展开目标地址。
- 表格行用制表符分隔列；`<br>` 产生硬断行。
- `<pre>` 子树逐字保留空白与换行。
- 图片输出 `[图片]` 或 `[图片：替代文字]`。
- 非 pre 内容会折叠源码空白、trim 空行；pre 子树绕过这些规约。

```mermaid
flowchart TD
  Start(["接收 ChapterContent"]) --> Kind{"kind 是 text 还是 nodes?"}
  Kind -->|text| ReturnText["直接返回 text"]
  Kind -->|nodes| Flow["flowText(nodes, verbatim=false)"]
  Flow --> NodeLoop{"遍历 ContentNode"}
  NodeLoop --> Rule{"rule 节点？"}
  Rule -->|是| FlushLine["收当前行但不产出字符"]
  Rule -->|否| Block{"块级元素？"}
  Block -->|是| BlockSeg["blockSegment → tr 走 rowText<br/>pre 子树 verbatim=true"]
  Block -->|否| Inline["inlineSegments 继续下钻"]
  Inline --> TextNode{"text/image/break/link/element"}
  TextNode --> Soft["软片段并入当前行"]
  BlockSeg --> Put["块片段先收行再入结果"]
  FlushLine --> End(["输出按 \\n 连接的段落"])
  Put --> End
  Soft --> NodeLoop
```

### 分页与偏移：`pagination.ts`
`followPages` 负责“翻页到底”：
- 按 `nextRule` 求下一页 URL，链式跟进。
- 多候选下一页不再递归翻页，而是全部抓取后统一去重。
- 五态停止：结束、本页零新增、回环、上限、串章边界。
- 串章保护优先使用 `stopUrls`，否则回退到启发式 `isSameChapterPage`。

```mermaid

  Q(["队列放入起始页"]) --> Pop{"取出一个页面"}

  Seen -->|是| Pop

  Fetch --> Extract["extract(page) 得到条目"]
  Extract --> Dedup{"条目 key 去重"}
  Dedup --> ZeroNew{"pageItems.length === 0 ?"}
  ZeroNew -->|是| StopZero["stoppedBy = zero-new"]
  ZeroNew -->|否| NewCount{"newCount === 0 ?"}
  NewCount -->|是| StopLoop["stoppedBy = loop"]
  NewCount -->|否| NextEval["subEval(nextRule)"]
  NextEval --> NextList["绝对化 + 去重 + 丢空"]
  NextList --> StopCheck{"是否命中 stopUrls 或跨章？"}

  More -->|是| Pop
```

### 流式导出：`export.ts`
`exportBook` 是一个异步生成器，用于 PDF/TXT 等格式的分章写入：
- 首字节输出 BOM，兼容 Windows 记事本。
- 校验 `from/to` 必须在 `[1, toc.length]` 且 `from <= to`。
- 逐章调用 `getChapter`，失败即停并在文件中插入中断标记。
- 每章之间默认延迟 300ms，避免连续抓站。
- 可通过 `AbortSignal` 取消。

```mermaid
sequenceDiagram
  participant Caller as "调用方"
  participant Export as "exportBook"
  participant Deps as "ExportDeps"

  Caller->>Export: 传入 title/from/to/signal
  Export->>Deps: getToc()
  Deps-->>Export: ChapterEntry[]
  Export->>Export: 校验 from/to 越界
  alt 合法范围
    loop 逐章
      Export->>Deps: getChapter(index)
      Deps-->>Export: chapterText
      Export-->>Caller: yield 章节标题+正文
      Export->>Export: sleep(delayMs)
      alt signal.aborted
        Export-->>Caller: 提前结束
      end
    end
  else 越界
    Export-->>Caller: throw Error
  end
```

### 阅读会话与进度：`reader-session.ts`
`ReaderSession` 是阅读时序的唯一持有者，职责包括：
- 打开一本书：拉目录、恢复存档位置、初始化已载数组。
- 加载单章：单在途槽，并发与滚动风暴去重。
- 预取下一章：委托 `reader-load.ts` 判断是否需要加载。
- 位置提交：`restore/jump/cross/scroll` 四种原因控制是否立即落盘。
- 跳转落地：等待目标挂载后按像素偏移定位，并补写真实比例。
- 返回栈：正文链接、脚注、补充文档关闭都复用同一条返回语义。

### 内容加载策略：`reader-load.ts`
`reader-load.ts` 提供两个纯函数：
- `nextChapterIndex`：从视口所在章向后找第一个未载章。
- `nextLoadTarget`：若已有在途章则拒绝新请求；若未载边界尚未进入预取区则返回 null。

预取窗口固定为 **2 屏**：当未载边界哨兵进入“视口底部 + 2 屏”以内时，发起加载。

```mermaid
flowchart TD

  HasInflight -->|是| NullReturn["返回 null"]
  HasInflight -->|否| NextIdx["nextChapterIndex(chapters, from)"]
  NextIdx --> HasNext{"存在未载章？"}
  HasNext -->|否| NullReturn
  HasNext -->|是| PreloadZone{"sentinelTop < viewportHeight × (1 + 2) ?"}
  PreloadZone -->|是| ReturnNext["返回下一个未载章下标"]
  PreloadZone -->|否| NullReturn
```

### EPUB 图文阅读：spine 计章、原书目录、脚注附录
EPUB 读取分两层：
- 包层 `package.ts`：解析 mimetype、container、OPF、manifest、spine、nav/NCX，构建 `EpubPackage`。
- 文档层 `documents.ts`：扫描 XHTML 建锚点映射，转换白名单节点，绑定图片与链接。

关键规则：
- spine 是阅读主序列；nav/NCX 是导航树，二者不是 1:1 对应。
- spine 中 `linear="false"` 属于补充文档，不参与主阅读流。
- 文档层两遍走：第一遍建锚点与链接集合，第二遍铸节点。
- 活动元素、脚本、样式等被剥离并记告警；内联 SVG 可能整页降级为封面图。
- 重复锚点报错；被剥离子树中的锚点只能降级而不能让整本书静默不可读。

```mermaid
flowchart TD
  Archive["EPUB 归档"] --> Package["readEpubPackage(package.ts)"]
  Package --> Spine["spine 主序列"]
  Package --> Nav["nav / NCX 导航树"]
  Package --> Manifest["manifest + cover"]
  Spine --> Doc["documents.ts scanXhtml + convertXhtml"]
  Nav --> Navigation["导航目标 path+fragment"]
  Doc --> Anchors["锚点映射 id → nodeId"]
  Doc --> Nodes["白名单 ContentNode 树"]
```

## 性能优化

### 预取窗口
- 预取距离：2 屏。
- 触发条件：未载边界哨兵进入“视口底部 + 2 屏”。
- 去重：`loading !== null` 时拒绝新加载；失败章不会自动反复预取。
- 推荐配置：若网络慢或站点限频，可在业务层扩大 `PRELOAD_SCREENS` 或增加导出节流时间。

## EPUB spine 计数异常排查

### 常见现象
- 阅读器显示的总章数与 OPF spine 长度不一致。
- 某些章节出现在目录里，但不在阅读顺序中。
- 导入后提示导航降级或资源被加密。

### 排查步骤
1. 确认 spine 主序列：
   - 阅读单元数量应基于 spine 中的线性条目，而不是 ZIP 条目顺序或文件名排序。
   - `linear="false"` 的 spine 项属于补充文档，不计入阅读主序列。
2. 检查导航来源：
   - 优先使用 nav 文档；无 nav 时用 NCX；两者都缺才降级为按 spine 合成。
   - 声明了导航文档却读不出目录，属于坏目录，不应静默降级。
3. 检查加密资源：
   - spine 中任意文档被加密 → 整本拒绝。
   - spine 之外的资源被加密 → 保留告警，实际用到时报“被加密”。
4. 检查文档层问题：
   - 重复锚点会直接报错。
   - 内联 SVG 若整页唯一内容，可能被当作封面候选；其余内联 SVG 会被剥离并记录告警。
   - 被剥离子树中的锚点只能降级，不能视为锚点不存在。

```mermaid

  Start(["EPUB 导入"]) --> CheckSpine["检查 spine 线性项"]
  CheckSpine --> Linear{"linear 是否为 true？"}
  Linear -->|否| Supplement["补充文档，不计阅读主序列"]
  Linear -->|是| Count["计入阅读章数"]
  Count --> NavCheck{"是否存在有效导航？"}
  NavCheck -->|是| UseNav["使用 nav/NCX 导航树"]
  NavCheck -->|否| Synthesize["按 spine 合成导航并告警"]
  UseNav --> Done(["完成"])
  Synthesize --> Done
  Supplement --> Done
```

## 故障排查指南

| 问题 | 可能原因 | 处理建议 |
|---|---|---|
| 阅读器卡在第一页 | 目录未加载成功或存档恢复失败 | 调用 `retry()` 重试；查看错误信息；确认书架可拉取。 |
| 跳章后进度没更新 | 跳章发生在加载在途期间，读数被 `pendingJump` 屏蔽 | 等待 settleJump 落位；若目标章失败，先重试该章。 |
| 导出范围报越界 | `from/to` 不在 `[1, total]` 或 `from > to` | 由路由层裁剪后再传；不要自己再次 clip。 |
| 导出中途失败 | 某章抓取失败 | 检查网络与源站限频；重跑可补缺章；查看文件中中断标记。 |
| EPUB 无法导入 | spine 文档加密、固定版式、脚本主内容、mimetype 不正确 | 查看导入告警 code；解密或移除限制后重试。 |
| EPUB 目录错位 | nav/NCX 指向错误或 spine 与目录不一致 | 检查 OPF spine 与导航文档；必要时接受 spine 合成导航。 |
| 滚动卡顿 | 已载章节过多、图片未懒加载、滚动未节流 | 确认未载章不入 DOM；封面使用 `loading="lazy"`；使用会话防抖。 |
| 章节文字丢失 | 自定义 CSS 或主题覆盖导致内容被隐藏 | 检查纸张色与正文色对比；还原默认主题验证。 |

## 结论
阅读器以 `ReaderSession` 为中心，把目录、正文、位置、预取、导出、EPUB 图文统一到一个可测的时序模型中。`chapter-content.ts` 保证文字面唯一投影，`pagination.ts` 保证翻页到底的安全终止，`export.ts` 保证导出可控、可中断、可续跑，`reader-load.ts` 保证预取只在正确时机触发，而 EPUB 层把 spine 主序列与原书导航解耦，使阅读顺序稳定、导航可诊断。对用户而言，最关键的体验是：滚动流畅、预取自然、导出可靠、主题可调、EPUB 可读。对开发者而言，最重要的纪律是：**不并行抓章、不静默丢弃可见内容、不复制越界判据、不在异步续作上污染旧会话**。

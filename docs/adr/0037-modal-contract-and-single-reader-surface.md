# 浮层分两家人：带遮罩的模态归一个 dialog module，阅读器的角落面判「至多一角」

Status: accepted

**模态契约**：带遮罩浮层的行为——Esc 退出、入场焦点落面板内带 `data-dialog-initial` 的元素（未标时才是**第一颗未禁用钮**）、Tab 圈认面板内全部可聚焦件（拖放区 / 文本框也算）、关闭后焦点还给触发件、遮罩点空退出、`role=dialog` / `aria-modal` 标记——住 `client/views/dialog.tsx` 的 `Dialog` 一处；调用方只交标题、内容、动作行与归还对象。键盘与焦点那一半由同文件的 `useDialogContract` 导出，无遮罩的听书设置卡复用其中一半。为什么必须收：这套口径此前每加一处浮层就被手抄一遍，已经漂成两种行为；入场焦点不给 `initialFocus` 旋钮（契约猜不出哪颗钮是安全的那一颗），无障碍名默认取可见标题，`busy` 不进契约（否则与调用方按钮禁用态各长一份真相），焦点 effect 挂载作用域（空依赖 + `onClose` 走 ref——曾被两处真缺陷教过：依赖带闭包时，任务轮询每秒重渲染会把焦点劫回第一颗、归还对象被重捕获成模态内按钮）。**阅读浮层**：Aa／目录／导出／注释／导入说明**至多一角在场**，判据住 `client/reader-surfaces.ts`；换角时注释面板只收不消费返回项，Esc 走「关闭」那条语义。互斥的 why：这些面同住右上角且各自成 absolute 层，两面上场时**底下那面看得见点不动**（命中测试打到上面那块），而互斥此前散在四个 opener 的 `setX(false)` 抄写里，一漏就叠。**同场 Esc 的归属**：一次 Esc 只收最上面那一层，认领顺序 = 打开顺序，住 `client/views/dialog.tsx` 的 `claimKeyLayer`，两家人（模态、阅读浮层）都到这一处认领。一处行为变更：`Aa` 上场也收目录抽屉。被否决：保持各视图自持 effect；把 `Dialog` 塞进 `bits.tsx`；抽屉与模态合成一套标记；阅读浮层做成 reducer；借会话持有浮层在场。

锚点：`src/client/views/dialog.tsx`（`Dialog` / `useDialogContract` / `claimKeyLayer` / `FOCUSABLE`）；`src/client/tts/TtsSettings.tsx` 的 `TtsSettingsPanel`；`src/client/reader-surfaces.ts`（`openSurface` / `closeAll` / `dismissSurface` / `maskFor` / `escOwner`）；`src/client/reader-session.ts` 的 `closeSupplement`；`tests/client/dialog.test.tsx`、`tests/client/reader-surfaces.test.ts`、`tests/client/tts-bar.test.tsx`、`tests/client/wiring-reader.test.tsx`。

# 决策索引

每篇一个决定，只记**难逆 + 无上下文会让人惊讶 + 当初真有过替代方案**的那三类。写作、状态与取代规则见 `docs/adr/ADR-FORMAT.md`；状态以每篇文件头为准。

「为什么这么切」的总体形状在 `docs/architecture.md`，不在这里重复；读数与欠账在 `tests/legado-coverage/matrix.ts`。本索引只做导航：每篇在下面恰好出现一次，编号只追加、别重排（断号即有人抄不到那一页）。

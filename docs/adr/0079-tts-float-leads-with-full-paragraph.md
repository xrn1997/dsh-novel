# 听书浮窗展开态整段可读，控件加大，收起态退成身份条

Status: accepted

浮窗展开态的第一职责是「这一句念到哪」，两行截断装不下一个自然段：正文区改吃剩余高度、装不下才在尾行挂「看全文」；运输行控件加大到各自可点的档位；收起态不再显示半截句子，只留播放环、身份、段号与一条章内进度细线。

## 背景

旧版（`ADR-0074`）把当前句立为主位，但形态尺寸被常量钉死：展开边栏里正文只拿到一小条，剩下给了头行、八颗小控件与进度条；收起胶囊里句子只剩两行短字。真实自然段常见上百字，「看不全」是算术结果，不是字号口味。同一份高度上还叠着三条结构问题：头行最左的 grip 点阵与「整行本来就能拖」重复；收起钮与设置钮并排紧挨；胶囊整块都接 pointerdown，位移过阈值就吞掉点击。

## 决定

1. **展开态四行骨架**：顶行 = 身份钮（点收起 / 拖移动）+ 设置钮两颗兄弟按钮；正文区吃剩余高度，截断时尾行右下角挂「看全文」（走已有的 `backToReader`）；运输行 = 回阅读器 / 上一段 / 播放 / 下一段 / 停止，控件尺寸升到便于触控的档；底行 = 语速 / 段号 / 章内进度条 / 定时倒计时，纯读数。
2. **正文区可拖不可点**：拖动 = 移动，点击无动作；「看全文」、进度条、设置钮、环都是真控件，从它们起手不拖也不 resize。
3. **位移阈值住实现**：阈值区分手抖与真拖，拖动后补发的 click 由根节点捕获层统一吞掉（胶囊与边栏共用一份）。
4. **收起态退成身份条**：播放环（包播放 / 暂停钮）+ 书名 + 段号徽标 + 底部一条章内进度细线；句子只在展开态出现，一出现就是完整的。
5. **空章不塌骨架**：正文区居中显示「本章没有可朗读的段落」，进度条不渲染；底行在没有其它读数时整行不渲染。

## 边界

- 浮窗仍不是阅读器：不滚动、不翻页、不做选词；读全文回阅读器。
- 封面仍归书架与详情页；浮窗不新增封面 URL 依赖。
- 浮窗只有一条章内进度：收起态细线与展开态进度条同算式、同 value，仍是段粒度；段内时间读数不进界面。
- 两个完整形态、不做半隐与 hover 抽屉；尺寸可调的裁决住 `ADR-0080`。

## 被否方案

- 逐句跟读：句是本仓不存在的粒度，且浏览器直出型音频没有时长读数，同一个浮窗会为两种引擎长两张脸。
- 只留一行 + 一键回阅读器：没有回答「在浮窗里一次看全当前段」，只是把责任推给一次点击。
- 保留两行截断、只调字号或补第三行：仍在窄坑位里做文章，控件命中尺寸也没有余地。

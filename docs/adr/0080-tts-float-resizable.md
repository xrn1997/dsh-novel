# 听书浮窗展开态尺寸可调：拖边 + 三档，现场记意图

Status: accepted

展开态宽高交给用户：左 / 右 / 下三条边与右下角可拖（对边锚定），范围 260–520 / 162–420；设置弹层给三档与复位，作为不用指针的人的等价入口。现场只记**意图**（`w` / `h`，null = 缺省），呈现时再夹取，夹取不回写。

## 背景

`ADR-0073` 的自由落位只给了位置两维，形态尺寸仍由常量钉死（168×56 胶囊 / 280×140 边栏）。`ADR-0079` 把展开态改成整段可读后，遮挡预算无法再由一个常量替所有人决定：同一块浮窗，有人读长段落需要更大，有人只想让它别挡正文。

## 决定

1. **可拖的边**：左、右、下三条边 + 右下角，命中带 8px；顶边不做把手——顶行是移动 / 收起面，同一方向上两种拖意会打架。
2. **命中带画在面板 padding 圈里**（左右 12 / 底 10 ≥ 8）：任何尺寸下都不与控件重叠，贴边时也不会被屏幕裁掉；因此不需要「控件优先还是 resize 优先」的仲裁。右下角 14×14，底行右侧预留 14px。
3. **对边 / 对角锚定**：拖右边时左缘不动，拖下边时顶缘不动；每轴夹进范围后把中心夹回视口。松手**不做近边吸附**——吸附只属于移动。
4. **范围**：宽 260–520、高 162–420。最小高是骨架算出来的（边框 2 + 上下 padding 20 + 顶行 28 + 正文一行 20 + 运输行 44 + 底行 24 + 三道 gap 24 = 162），最小宽要容得下运输行五颗 ≥32 的钮。缺省 320×200。
5. **呈现尺寸独立于意图**：`resolvedMiniBarSize` 每轴夹到 `[min, min(max, 视口 − 16)]`，视口比下限还小就取下限（块可溢出，不崩）；夹取**不回写**——缩窗口再拉大，用户的值原样回来。
6. **现场字段**：`w` / `h` 与 `cx` / `cy` 同语义（`number | null`，null = 没调过）；解析认有限数，范围夹取只发生在呈现时；`commit` 的早退比较含五字段。
7. **拖边期间不落 localStorage**：与移动同一条节拍（同步 I/O × 60fps），松手 / 取消时统一 `persistMiniBarState()`；取消落的是最后一帧。
8. **三档与复位只投影给浮窗**：设置弹层里「小 / 中 / 大 / 复位大小」一行只在浮窗那份设置卡出现，阅读器条的设置卡不显示；`TtsSettings.tsx` 仍是唯一一份行清单，加的是 `surface` 投影而不是第二份抄本。
9. **收起态不参与**：胶囊固定 208×44——能调的胶囊就不是「不挡事」那一档了。
10. **尺寸走值槽**：`miniBarLayout` 把呈现尺寸写进 `--novel-tts-panel-w` / `--novel-tts-panel-h`，样式层只读变量；两个值槽在 `tokens.ts` 的 token 表里在册。

## 被否方案

- **数值滑杆放进设置弹层**：不加新交互面、有精确读数，但面板浮在浮窗上方——调的时候看不见结果，反馈链是断的。
- **只给三档预设**：实现与门最省、键盘天然可达，但不是用户要的「调整宽高」；340 宽这种中间值永远到不了。三档保留为等价入口。
- **胶囊也参与调整**：收起态失去「不挡事」这个唯一卖点，两个形态的尺寸会互相污染。

## 边界

- 尺寸是浮窗自己的现场，不进 wire、不进 `SHELF_META`，不跨端同步。
- 顶边不是 resize 把手；键盘改尺寸只走设置弹层的三档（方向键仍负责移动）。
- 位置（`cx` / `cy`）的裁决仍归 `ADR-0073`；本篇只把「现场只有中心 + 收起态」扩展为「中心 + 收起态 + 宽高」。

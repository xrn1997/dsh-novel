# 视口顶判据为什么改吃块区间：空档归下一项，三条数据路同口径

Status: accepted

章块高度不含章间 margin，浏览器对 scrollTop 的赋值又向整数吸合——落位差出的亚像素会停在两章之间的无内容带里；旧判据只看起点，把这条带读回「上一章 @1」，下一帧诚实读数把刚落定的跳章打回前一章。决定：**「视口顶落在哪一项」的判据从「吃起点」升级为「吃区间」——块尾严格在判据线之上、其后又有未越过的项时，线落在空档，归下一项；起点 `<=` 压线算越过的既有边界不动。**

## 背景

活体遥测（2026-11-25，桌面浏览器 100% DPI）钉出缺陷链：跳章落位差几个亚像素压不到下一章块顶，读数落进章间空档；`settleJump` 自己按目标章钳 0 提交，下一帧 `locateChapter` 走「最后一条已越过」判回上一章 @1，进度落盘随即回弹。只在进度侧修补会让同一像素在另外两条数据路（听书探针 `readingPositionAt`、正文节点 `currentNodeOf`）上答上一章——「从阅读位置起播」从顶条上方已不可见的上一段起播，顶条与目录却显示下一章；这正是 `client/viewport-top.ts` 当初收口要消灭的「落盘位置动了而跟读高亮不动」。

## 决定

1. **落项判据吃区间，不吃起点**：`crossedIndex` 的取项面改为 `ItemSpan`（起点 / 块尾，同为相对判据线的偏移）。边界成对——起点 `<=`（压线算已越过）、块尾 `< 0` 才算整条离线（块尾正压线仍是这块占着线，读到章底的正常位置不受影响）。已越过项里只要还有块尾 `>= 0` 的，线就被最后一条这样的项占着；最后一条已越过项离线而更早的覆盖项还在时，完整落在覆盖项跨度内的子块缝归下一子项，覆盖项自己的尾巴归覆盖项——嵌套块（父段尾部可见、段内图已离线）与并排单元格（左格高段跨线、右格短段已离线）不得被更晚的非覆盖项顶成空档。
2. **空档归下一项**：所有已越过项的块尾都严格在上线之上（`< 0`）、其后存在起点在下的下一项时，判据线落在空档（章间 margin、段间 margin——线上没有本项任何像素），归下一项。阅读位置的口径是「顶条下方第一条可见内容」（`ADR-0089`），空档里作数的只有下一项的第一行。
3. **规则只住主人家**：空档归属进 `crossedIndex` 本体而非各消费点——进度锚点、听书块矩形、正文节点矩形三条路同吃，落点归下一章 @0 时章内比例由 `ratioWithin` 天然钳 0，探针的段号由「本块内都未越过 → 回落首块」天然落开篇第一段。不给任何一条路留**缝归**例外。正文节点采集（`currentNodeOf`）与听书探针同构，先按章块过 `crossedIndex` 判章、再在本章内滤除不占独立纵向块带的行内短语与表格单元格节点（`isFlowNovelNode`），防止段内已滚出的行内元素盖掉父段触发假空档；短语词表与渲染降级共用 `shared/content-tags.ts` 的 `PHRASING_TAGS`，几何侧不自抄第二份。过滤后整章无候选时保留原候选（不丢锚点），该兜底只管「丢不丢锚点」，不是缝归例外。
4. **回落骨架不动**：一条都没越过 → 文档序第一个非空项；洞跳过；空表 → -1。零高项（没量到内容的块）压线时占线、离线时让位——与区间判据自洽，不另立规则。

## 被否方案

- **缝只归进度侧（例外收在 `locateChapter`）**：改动最小，但同一个像素在落盘与起播/跟读两处给出两个答案，`ADR-0089`/`ADR-0096` 的「同口径」断言作废；判据在主人家之外长出条件分支的第二形态，正是收口要根除的漂移。
- **收窄章间 margin 让缝消失**：布局层抹不平取整层——DPR≠1 的设备像素吸整与滚动条拖过仍会把读数送进任何非零缝；且段间缝同样存在，缝归谁的语义不能靠 CSS 侥幸。
- **只在赋值侧向上取整（`fefcefd` 已做）**：那是第二层补丁，管「落位别进缝」；本判据管「进了缝也不许回弹」。两层各自有钉，不许互相冒充。

## 后果

- 缝内读数三条路一致归下一项：顶条/目录高亮、「从阅读位置起播」与段落落点守卫（滚动→翻页交接按章号相等才用精确段落）不再互相拆台。
- **锚点与赋值两层各自收口**：块高是空档判据的一半——布局帧、跨章提交前与渲染后拍点都用同版锚点（`handleViewportChange` / `afterRender`）；恢复 / 跳章 / 排版复位 / 段落落位 / 滚动补偿的赋值点统一先向上取整再钳底到 0。取整钳底是第二层补丁，不许冒充判据。
- 旧存档无需迁移：块尾正压线那一像素仍读作「上一章 @1」，缝内读数改判「下一章 @0」。恢复落位取整把内容顶推过块尾的那一帧可能多写一笔 @0，此后即为不动点。
- 合成页夹具必须忠实（块内无无主带，缝只在块间）：稀疏假节点会被空档判据误翻进下一章，钉子会钉在假几何而不是判据上。

# 听书浮窗以当前句与阅读控制为主，身份退为一行小字

Status: superseded by 0079

浮窗常驻时最该被读到的是正在念的那一句和手上的控制，而不是书目身份：封面退场、书名降为一行次要小字，当前句扩成两行主字阶，浮窗只留一条章内进度条，播放环收回紧凑档。两个形态、紧凑密度、进度不撒谎与自由落位不变。

## 背景

旧版的收起胶囊里，封面首字占掉一截横向空间，书名与当前句同排一级；展开边栏的头行也把封面和书名放在第一眼，当前句只剩一行小字截断。展开边栏还同时摆着段内时间滑杆与章内进度细线两条进度：前者把阅读器条的时间轴又抄了一遍，后者才是浮窗要回答的「这一章读到哪」。浮窗里的「封面」本来就不是封面——播放层不持封面 URL，它只是书架首字色块的缩小版——却把最贵的一行横向空间占去。身份是书架与详情页的职责，浮窗只需要认出「这是哪一本」；用户在这个小方块里要的是「正在读什么、能马上按什么」。

## 决定

- **封面退场**：浮窗两个形态都不再渲染封面位，也不再依赖首字与色档投影。省下的空间让回当前句与身份行，不再有纯装饰占宽。
- **书名降级为身份标签**：书名降到最小字阶、次要字色、单行省略；章段读数仍是它下面更小一档的副行。身份仍可辨认，但不再和正文抢视线。
- **当前句升为主位**：展开态两行主字色，收起态两行次一档；两种形态都给两行**固定高度**（短句也占满），换段时控件不跳；全文仍留在 `title`，不做滚动。
- **只留一条章内进度条**：段内时间滑杆从浮窗退场，浮窗与阅读器条都只剩章内这一条（`ADR-0075`）；底部细线改成可拖的章内进度条——填充按段号 + 段内比例推进，拖动即跳到目标段。一条控件同时承担读数与导航。
- **播放环不再是英雄按钮**：两个形态的环都收到紧凑档；控制件一件不少，正文变多不换能力，也不改行序。**本档不承诺 32px 触控目标**：紧凑档的实测尺寸是图标钮 24×24、chip 高 20、播放环 28（胶囊 30）、章内进度条命中带高 18，几何门把动作钮与进度滑杆的下限钉在 ≥20 / ≥16。命中盒就是视觉盒本身，不另铺透明热区；靠 4–6px 间距与头行 / 运输行的分组降低误触。约束来源是固定尺寸的两个形态——280×140 边栏里要放下上一段 / 播放暂停 / 下一段 / 语速 / 定时 / 回阅读器 / 停止 / 设置八件控制，按 32px 命中盒排布会把当前句的两行主位挤掉。停止与收起分置运输行与头行，误触不会直接断会话。
- **形态与位置不动**：168×56 胶囊 / 280×140 边栏、两个完整形态、自由落位、进度不撒谎继续按 `ADR-0073`。

## 边界

- 浮窗仍不是阅读器：两行截断、不滚动、不翻页、不做选词；读全文回阅读器。
- 收起态不补第二排按钮：胶囊只留进度环、身份小字、段号与当前句；完整控制在展开态。
- 封面仍归书架与详情页；浮窗不新增封面 URL 依赖，也不承诺任何封面回退形态。
- 身份小字不是可删项：多本书轮着听时，它是「现在放的是哪本」的唯一读数。
- 段内 seek 从界面退场（`ADR-0075`）：浮窗不再摆第二条时间轴；章内进度条是段粒度，不冒充段内计时。

## 被否方案

- **保留封面、只缩书名**：封面是浮窗里最占横向的纯装饰，缩书名只挪了字号；当前句仍是一行截断，主次没变。
- **保留两条进度条、只把上面那条调细**：两条进度各说一件事，读者仍要先分辨哪条能拖；浮窗的宽度与高度都用在重复的读数上。
- **只删上面一条、底部继续留只读细线**：移除唯一可拖的进度控件后，浮窗只能靠跳段键一格一格走；把底部改成可拖的章内条才补回导航，不必再养第二条。
- **正文铺三行或让浮窗可滚**：控制器会变成第二个阅读器，遮挡变大、交互变复杂，「回阅读器」这条主路径也被削弱。
- **把每颗控制件都做成 32px 命中盒**：32px 是独立按钮的触控下限，两个形态却是固定尺寸的常驻小块——280×140 的边栏里要放下八件控制，命中盒放大后头行与运输行各自撑高、当前句的两行主位被挤掉，等于退回「能力齐全但遮挡远大于控制需要」的媒体卡形状；168×56 的胶囊更放不下。折中是命中盒取视觉盒、用间距与分组避免误触，几何门把下限如实钉在 ≥20 / ≥16。
- **去掉书名只留章段**：切书时认不出身份；书名本来就只占一行小字，删掉省不下结构。

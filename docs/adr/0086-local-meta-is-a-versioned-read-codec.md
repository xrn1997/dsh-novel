# 本地书落盘元数据是版本化读 codec：旧形状读时归一、认不出的版本具名拒绝

Status: accepted

`local/<uuid>.json` 是跨版本读的文件：应用升级后要能打开旧书，格式演进要能拿旧形状做一次显式归一。决定把「磁盘形状 → 当前内存形状」收进一个 codec：一处读文件、已知旧形状归一成当前形状、未知版本或 format 给具名拒绝。此前版本判别是读面里一个严格等式，旧形状兼容只有告警那一处临时分支——抬版本会让全部存量 EPUB 落进 TXT 分支，给记录加读面字段则旧书静默 `undefined`。

## 决定

- **版本分流先于格式分流**：顶层元数据缺席 `schemaVersion` 且不带 `format` 就是 TXT（旧书零迁移，`ADR-0014`）；带 `format` 却缺版本号是认不出的形状（可能是丢了版本号的新形状），具名拒绝、不按 TXT 的偏移表读；`schemaVersion: 2` + `format: 'epub'` 是 EPUB，它同时是发布完成的提交标记。版本号或 format 认不出时抛具名错误，**不猜**、也不落进另一条格式的读法。
- **旧形状只读时归一、不回写磁盘**：归一结果只进内存形状；回写要把整份元数据重写一遍，而它只影响读面（写盘时机只有导入）。加一个读面字段时，在解码的归一分支给旧书默认值，并加一条「旧 meta + 新字段」用例——这就是本文件对格式演进的承诺。
- **写入处声明存储形状**：发布处以存储形状（TXT 与 EPUB 各一份）声明盘上有什么；章序列 / 文档表 / 资源表的**元素形状**仍 import 自导入层，不是第二张字段表——元素里有什么由导入层说了算，导入端加字段读端不必跟。
- **告警两形态归一成一列**：旧书只有拼好句子的 `warnings` 投影，新书另写事实清单 `findings`；读 codec 归一成当前内存形状的一列，读面不再各自判形态。

## 被否方案

- **维持严格等式判别**：抬版本即全量旧书落进另一条格式的读法（找不存在的 `.txt`），等于升级即全部本地书打不开。
- **回写式一次性迁移**：把整份元数据重写一遍换取「磁盘上只有一种形状」；代价与收益不成比例——它只影响读面，而写盘时机只有导入，回写会引入一次没有需求方的写路径。
- **未知版本静默回落 TXT**：把「读不懂」说成「另一种格式」，是「宁炸不猜」在存储面被反过来执行；具名拒绝让损坏可见，代价是损坏文件从「碰巧能读」变成 500。
- **为存储形状再抄一份字段表**：抄一份的下场是导入端加字段、存储端不知道；共享元素形状的 import 才是单一来源。

## 边界

- codec 只管 meta 文件的版本与形状，不管目录 / 正文 / 资源的语义（归 `services/epub/`）与本地书的身份 / 分流（归 `services/localbooks.ts`）。
- 不引入周期性扫描或自动修复：损坏按具名错误交回调用侧，`ADR-0013` 的「不存在与损坏绝不折叠」口径不变。
- 补数（`totalChapters`）仍是门面启动时的一轮投影（`ADR-0058`），不是 codec 的职责。

## 代价

旧书若顶层形状损坏（缺必填格）从「碰巧能读」变成具名 500——这是「宁炸不猜」的代价。新增一个读面字段要同时写一条「旧 meta + 新字段」用例，比随手加字段贵一点；换来的是旧书不会静默缺字段。

锚点：`src/services/local-meta.ts` 的 `LOCAL_META_SCHEMA_VERSION` / `StoredTextMeta` / `StoredEpubMetaV2` / `decodeLocalMeta` / `LocalMetaVersionError` / `LocalMetaFormatError`；消费点 `src/services/localbooks.ts` 的 `metaOf` 与写入处（`publishText` / `metaOfImport`）；钉子 `tests/services/localbooks.test.ts` 的「旧 meta 缺新读面字段」「未知版本 / format 具名拒绝」；`ADR-0014`（本地书与 TXT 零迁移）、`ADR-0058`（补数形状）、`ADR-0063` 决定 6（一处兼容泛化成格式策略）、`ADR-0013`（不存在与损坏绝不折叠）。

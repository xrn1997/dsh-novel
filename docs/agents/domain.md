# Domain docs

工程技能探索代码库时，如何消费本仓的领域文档。

**本仓是单上下文**：领域文档只有仓根一份 `CONTEXT.md` 加 `docs/adr/` 一处决策。改代码前先读 `CONTEXT.md`，再读与改动区域相关的 ADR；输出里点名领域概念时用词表里的词，别漂到 `_Avoid_` 列出的同义词。

需要的概念还不在术语表里，本身是个信号：要么在发明项目不用的语言，要么真有缺口。你的输出若与既有 ADR 相矛盾，显式挑明，别静默覆盖：

> _与 ADR-0002（「没取到」与「取到空」是两种值：`src/engine/select.ts` 的 `reducePicked`）矛盾，但值得重开，因为……_

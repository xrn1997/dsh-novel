# 界面规格（现行）

结构与层级以本文为准；像素值、断点、文案键的唯一定义在 `src/client/` 与 `tests/client/`，本文不抄读数。历史取舍在 git 与 `docs/adr/`，这里只写现在长什么样。架构形状与主人清单见 `docs/architecture.md`。

## 1. 入口与面板

- 槽位注册见 `docs/architecture.md` §3；本节只说面板内的 tab 与跨 tab 现场。运行参数走插件详情页的配置卡（本文 §5）。
- 三个 tab 住 `src/client/views/NovelView.tsx` 的 `TABS`：**书架** / **书城** / **书源管理**，切换走 `navigate`。`src/client/store.ts` 的 `ViewRoute` 另有 `search` 与 `reader` 两态：它们是 tab 之下的沉浸流，顶部 tab 条不随行；两条返回都固定落书架（书城→详情→阅读这条链也不回书城）。
- 跨 tab 现场是模块级的，切 tab 不丢：书架读面与落架账（`panelShelf`）、书源列表态（`sourceListUi`）、书城选中态（`cityStore`）、任务弹层入口（`requestJobOpen`）、听书播放会话（`ttsPlayer`）各自在场；归属见 `docs/architecture.md` §4 的「浏览器视图内路由与跨卸载现场」与「听书播放层」两行。状态层的任务入口可以切到书源 tab 并直接打开导入弹层或滚到任务卡。
- 面板只做呈现与投影：书架真相、搜索轮次、任务态都在 Node 半；客户端不持任何真相（见 `docs/architecture.md` §3）。
- 滚动条按宿主档主题化：面板自己的两棵树（`.novel-root` 与 `[data-novel-scope]`）的滚动面由 `src/client/styles/shell.ts` 统一成宿主滚动条语义，颜色取 `src/client/styles/tokens.ts` 的 `--novel-scrollbar*`；宿主 DOM 不碰。

## 2. 基础状态

| 状态 | 表达 | 规则 |
| --- | --- | --- |
| 加载中 | 骨架占位 | 书架在 `panelShelf.books === null` 时给骨架；书城在途补骨架卡。骨架不等于空态 |
| 空 | `EmptyState` + 引导动作 | 书架空给导入引导；书城空只认「干净跑完」（`city-view-model.ts` 的 `bookListEmpty`） |
| 失败 | `ErrorBanner` 或场景内联错误 | **不折成空**：书架读失败落「不可用」而不是空架；源清单读失败不落空表；目录未到不摆空目录 |
| 在途 | 按钮禁用 / 进行读条 | 书城换源立即提交；任务卡与体检各自报进度 |
| 不可用 | 入口不渲染 | 没有可渲染的东西时入口直接消失，不造禁用态冒充（`returnDepth` / `hasImportNotes` / `hasMore` 为假即不渲染） |
| 部分失败 | 失败源折叠点名 | 搜索里逐源失败不拖垮整页：失败源进页尾折叠区，点名 code / message / statusDetail |

错误有两条泳道：场景内联走 `src/client/views/bits.tsx` 的 `ErrorBanner`（留在出事的块里，可重试）；全局通知走 `src/client/transient.ts` 的 `pushError` / `pushOk`，由 `src/client/views/NovelStatusOverlay.tsx` 的 `GlobalStatusBar` 呈现——sticky 的错误可带锚点做「定位」，成功提示按 TTL 熄灭。

## 3. 各视图与清单

### 3.1 书架（`src/client/views/ShelfView.tsx`）

- 头：标题、搜索框（关键字只作聚合搜索的跳转输入）、筛选与多选入口。
- 筛选住 `shelf-view-model.ts` 的 `SHELF_FILTERS`：全部 / 在读 / 未读 / 本地；未读 / 在读按进度读数判，不在这里复述。
- 多选是组件态，切 tab 清零；筛选让位给批量条；「全选」只覆盖当前筛选可见；单本 ✕ 与「删除所选」走本文 §4 的确认模态。
- 本地导入在网格末位给引导卡，空架另有兜底卡；导入带持久告警时回执留在本页，没有告警则直接进阅读器。

### 3.2 书城（`src/client/views/CityView.tsx`）

- 左栏：源列表（可搜）；选中源就地展开它自己声明的分类（可搜）。选源选类都立即提交，不攒「开始浏览」。
- 进入判据住 `city-entry.ts` 的 `decideCityEntry` / `resolveCitySelection`：自动那条路做源/分类回落，只问一次，然后提交或跟随。
- 态：在途补骨架；空态只认干净跑完；错误走横幅；无源是独立空态（`cityEmptyState === 'no-sources'`）；续页只认 `round.hasMore` + `loadMore`，尾行给本轮读数。
- 右侧书目是**按源**的，不跨源合并；顺序听源。

### 3.3 书源管理（`src/client/views/SettingsSection.tsx`）

- 组成：待办收件箱（`InboxSection`，可忽略 / 重新显示）、任务槽（`ProbeRunCard`）、源列表（`SettingsSourceList.tsx` 的 `SourceList`）与导入弹层（`SettingsImportPane.tsx` 的 `ImportPane`）。
- 导入：拖放 / 多选文件，另有折叠的粘贴道；提交即关弹层，结果回待办。
- 列表：状态带、文本 / 状态 / 分组过滤、编辑态批量条、六列表格、前端分页（步长是代码常量）。
- 行：状态徽标、验证 / 重验、试跑下钻（`ProbePane`）、「⋯」菜单、最右启停开关。启停是乐观写，失败回滚并在行锚点标红边。
- 删除源走本文 §4 的确认模态；启停不做二次确认。

### 3.4 搜索（`src/client/views/SearchView.tsx`）

- 入口：书架头搜索框与搜索页表单；`route.keyword` 消费一次即摘除。
- 结果页：进度读数 + 收口摘要（`client/copy/search-summary.ts` 的 `searchSummarySegments`）。
- 空态两分支：没有可搜的源 / 搜了但零命中。
- 默认按书视图（`search-view-model.ts` 的 `deriveRound`，只收 `kept`）：每本一组逐源行，「都加架」三态，回执分三笔（成功 / 仍缺 / 无地址）。
- 逐源详情降级到页尾 `<details>`：组头带状态徽标，suspect 组在组内折叠，失败源折叠并点名错误；无地址的命中渲染为 dead 行。

### 3.5 阅读器（`src/client/views/ReaderView.tsx`）

- 连续滚动，只渲染已载章节。向后的预取判据住 `reader-load.ts` 的 `nextLoadTarget`（哨兵 + 两屏）；向前的保留深度是 `KEEP_BEHIND`，由 `pruneToViewport` 裁。视口顶接近窗口顶时 `checkBackfill` 补上一章，每个视口 episode 的补载次数有上界；窗口与补载的细节住 `client/reader-session.ts` 的头注。
- 滚动补偿归会话：裁章与前插在 `pendingScrollFixes` 记账，`afterRender` 按参考章新旧起点差补 `scrollTop`；浏览器的原生锚定在阅读器子树整棵关掉（`styles/reader.ts`），否则会补两遍。
- 进度：`ReaderSession` 的 `commit` 把恢复 / 跳转 / 滚动防抖统一落到 `saveProgress`；恢复不写，跳转与跨章立落。
- 阅读位置按**顶条下方第一行**算：顶条是 sticky 覆盖层，贴住视口顶后盖住内容最上面约 40px。`ReaderView` 把顶条实测高作为 `topInset` 交给会话，存（`locateChapter` 吃 `scrollTop + inset`）与取（恢复 / 目录与内链跳转 / 排版复位 / 返回原处落位减掉 inset）用同一个值；阅读探针（「从阅读位置起播」）同一口径。只给恢复让位、不给读数让位，每进一次阅读器位置就多漂一条条高——听书恢复的段首正是被顶条挡住的那一行。
- 浮层住 `reader-surfaces.ts` 的 `ReaderSurface`：偏好 / 目录 / 导出 / 补充正文 / 导入注释，**至多一角**；只有偏好与导出带遮罩，Esc 归属见本文 §4。导入注释列的是服务端持久化的每一条痕：哪一页读不出正文、哪一条目录被剪、哪一处图片没带进来；每条只说「哪一格、丢了什么、多少处」，面板不补发请求。
- 偏好面板（`ReaderView.tsx` 的 `PrefsPanel`）：字号 / 行距 / 栏宽 / 纸张色（含自定义）与强制深色；档位住 `prefs-ui.ts`，点遮罩关闭。
- 离开一问：`reader-scene.ts` 的 `ReaderScene` 只在书不在架（`onShelf === 'off'`）时问「加入书架」；入架成功才离开，失败只落内联错误、留在阅读器。

### 3.6 听书（`src/client/tts/`）

- **入口与起播**：阅读器顶条的「听书」pill 没有会话时起播——位置取阅读器此刻看得见的那一段（实时探针；量不到才退当前章首段），听书存档只提供音色 / 语速 / 音量与段级续听现场；本书正在听时 pill 是继续 / 暂停，再按不重置位置。pill 的选中态用随纸色现算的跟读字色（条底跟纸，选中色也跟纸；强制深色时回退宿主 brand）。正文选区另浮出「从本段听」：选区判定与浮钮住**阅读器一处**（`src/client/views/listen-from-selection.ts` 的 `useListenFromSelection` + `ReaderView`，document 监听只有一份）。
- **阅读器听书条**（`src/client/tts/TtsBar.tsx`）：只在正在听的会话就是本书时挂载；贴视口底、条底跟纸走。条上是上一段 / 播放暂停 / 下一段、段读数与当前段一行预览、语速读数（点一次切到下一档，越过 3x 回 0.5x）、定时读数（点一次切到下一档，按 关闭 → 15 → 30 → 60 → 本章结束 → 关闭 循环）、定位到正在念的段、设置与停止；末行整宽是章内段滑杆（拖到任意段即起播，空章不渲染）。语速与定时在条上直接改，不打开设置卡；设置钮是打开完整设置卡的唯一入口。本章没有可朗读段落时段读数是「本章没有可朗读的段落」。
- **设置面板**：在条上方展开，行序为语速、音色（源没有音色表时整行不渲染；浏览器直出按 `voiceURI` 去重、名字后挂语区，平台零音色时不出现、`voiceschanged` 迟到时补上）、音量、定时（关闭 / 15 / 30 / 60 分 / 本章结束）、引擎（当前值不在清单里时仍摆现值；换引擎时音色回退为该源缺省，音色 id 不跨引擎互通；换到直出源先等平台语音表，等不到才报错、选择不生效）、起播章、动作（从阅读位置起播 / 上一章 / 下一章）与一句「听书与阅读共用进度；音色、语速与音量按书记住」。**语速滑杆上写的始终是用户要的倍率**：引擎自己念到哪儿由回执的补速决定，滑杆不拆成「引擎多少 + 补多少」（`ADR-0081`）。面板无遮罩、非模态，但 Esc / 入场焦点 / Tab 圈 / 关后还焦与模态共用 `views/dialog.tsx` 的 `useDialogContract`。设置钮是唯一打开这张卡的入口，也是开关：再点一次收起，Esc 只收弹层、不连带收起承载它的浮层本体（层序见本文 §4）；条上的语速 / 定时单击循环不经过这张卡，卡里的滑杆与档位作精调。
- **失败提示**：单段失败只跳过，连续失败到阈值才暂停；暂停时在听书条 / 浮窗上留一行提示，错误码经 `client/tts/tts-error.ts` 的 `ttsErrorMessage` 翻成人话，不裸露 `TTS_*`。
- **跟读高亮与视口跟随**（`src/client/views/ChapterBody.tsx`）：本书本章正在听时，命中的正文块换文字色（`--novel-live-ink` 按纸色现算），并在段首框外画一枚 currentColor 小三角；不铺底色、不加竖条、不画段内进度线（`ADR-0076`）。高亮不改布局，注释面板里收掉三角。视口跟随：播放推进到新段 / 新章时把视口带到当前段——目标在看得见的正文带里不动，离开才居中；读者手动滚动（滚轮 / 触摸 / 滚动键 / 滚动条拖动）或点目录 / 内链 / 返回原处后跟随让位，按听书条的「定位到正在念的段」重新接上并居中（`ADR-0091`）。
- **全局迷你条**（`src/client/tts/TtsMiniBar.tsx` / `TtsMiniPanel.tsx`）：注册在宿主 `shell.overlay`，与状态层同一次 inject、两枚条目。缺省是**身份胶囊**（进度环包播放钮 + 展开钮；身份区只给书名与段号，底边一条章内进度细线）；点身份区展开成**边栏**（顶行身份钮 = 点收起 / 拖移动，正文区整段上屏，运输行回阅读器 / 上一段 / 播放暂停 / 下一段 / 停止，底行只摆当下有的读数）。收起态与展开态共用块中心；松手时近边的边才贴齐，展开态尺寸可拖边调整，设置弹层里另有小 / 中 / 大三档与复位（`ADR-0073` / `ADR-0080`）。设置卡上方优先展开，下方真的更大才翻过去；两侧都放不下时高度收到那一侧余量、卡内滚动，不探出视口。位置与尺寸落 localStorage，视口变化后贴着的边继续贴。
- **在场与快捷键**：在场判据 = 会话在 ∧ 阅读器在场书键集合里没有会话本书（阅读器里听本书时由就地条接管，读另一本时迷你条照常在场）。Space 播放 / 暂停、Shift+←/→ 跳段、Esc 收起，只在没有阅读器子树时装；焦点在浮窗控件上时 Space 归控件；拖动只在身份钮与正文区起手，拖动中整块光标为抓手（grabbing）、与悬停指针区分（胶囊身份钮悬停是 pointer，展开态拖面悬停是 grab）；拖边中整块光标跟随所拖边的 resize 指针，指针滑到中间区域也不变。
- **书架听书徽标**（`src/client/views/ShelfView.tsx` / `src/client/shelf-view-model.ts`）：卡片只有一条进度行（`progress`，阅读与听书共用）；「正在听」只标播放层此刻在放的那一本，暂停即撤下（会话仍在，迷你条还在）。徽标钉在**封面顶左**（出流的角标层，不吃任何一行文字的宽度）：多选态这一角归勾选标记，徽标让位；**封面底左**归出处身份——在线书是来源 chip、本地书是「本地」，两者由 `shelfSourceTag` 的判据互斥、同住一个槽位，因此源名与书名各得整行宽度。多选态只动顶左那一角，底左的出处身份照常在场。

## 4. 浮层与危险动作

- **带遮罩**（`src/client/views/dialog.tsx` 的 `Dialog`）：删书确认（单 / 批）、离开阅读器的入架一问、删源确认（单 / 批）、导入弹层（wide）、书籍详情（drawer）、删朗读引擎确认、朗读引擎编辑。
- **不带遮罩**：目录抽屉、阅读注释面板、导入注释面板、书源「⋯」菜单、行内登录、书架导入回执、全局状态层与状态条、听书迷你条，以及听书的两份设置卡（阅读器条内与浮窗弹层；它们复用键盘与焦点契约，不设遮罩）。
- 模态契约（Esc、入场焦点、Tab 圈、关闭后还焦、scrim 与 dialog 标记）只在 `src/client/views/dialog.tsx` 定义一次：带遮罩的浮层共读 `Dialog`，无遮罩的听书设置卡复用 `useDialogContract`。同场多层时 `claimKeyLayer` 按打开顺序仲裁——一次 Esc 与 Tab 圈只归最上面那一层，阅读浮层也到这一处认领（`ADR-0037`）。
- **危险层级**：确认框的主按钮用 `danger solid`（实心红）；行内删除用 `danger`（安静红）；启停这类可逆动作不设确认；导出先过范围面板再发。没有「清缓存」入口——缓存失效靠指纹入名（`ADR-0012`）。

## 5. 插件设置页的运行参数卡

- 挂点：宿主插件详情页的 `plugins.bundle.config` 槽位（按 bundle 包名寻址），由 `src/client/config-page.tsx` 的 `registerConfigPage` 注册；值与写协议走宿主设置面 `ctx.remote.settings` 的 `describe` / `mutate`，缺席时整页不出现。
- 版式是**一张卡、一条列表**：工具条（筛选框 + 分区选择器 + 仅看已改 + 改动计数）贴顶，保存条贴底常驻，中间是五段（搜索 / 阅读与导出 / 存储上限 / 网络 / 听书，`GROUPS`；段名以字典为准）自上而下、段内两列配对。只渲染 volatile 字段，启动期字段（如 `dataDir`）不出现。
- 每行一条框：左边是值，框内右侧是单位、人话回读或预设下拉。说明挂在标签后的问号上（悬浮 / 聚焦才浮出，不占布局）；已覆盖、未保存改动与单项重置各有标记。非法值由页面给出该字段的固定提示并标 `aria-invalid`，草稿原样留在框里。
- 找配置项：搜索框按显示名、说明与字段键名匹配，下拉给出命中的配置项（带分区与当前值），回车跳到并聚焦那一行；分区选择器是同一筛选面的粗筛入口。筛选期间分区一律展开。
- 状态：加载中 / 插件未加载 / 设置面读取失败由本页自绘；写入态（只读 / 保存中 / 保存失败）也自绘，保存失败保留草稿。焦点在本卡内时 `Ctrl/⌘+S` 保存、`Ctrl/⌘+K` 聚焦筛选；焦点在卡外不抢宿主同名键。
- **听书段**：五个标量缺省——默认朗读引擎、默认语速、默认音量、朗读音频缓存上限、朗读预取段数；只在本书没有听书存档时兜底。段末是对象数据管理区，默认收成一行「朗读引擎与订阅」，点开才挂载引擎清单（网络读面）。

# 界面规格（现行）

结构与层级以本文为准；像素值、断点、文案键的唯一定义在 `src/client/` 与 `tests/client/`，本文不抄读数。历史取舍在 git 与 `docs/adr/`，这里只写现在长什么样。架构形状与主人清单见 `docs/architecture.md`。

## 1. 入口与面板

- 槽位注册见 `docs/architecture.md` §3；本节只说面板内的 tab 与跨 tab 现场。运行参数走插件详情页的配置卡（本文 §5）。
- 三个 tab 住 `src/client/views/NovelView.tsx` 的 `TABS`：**书架** / **书城** / **书源管理**，切换走 `navigate`。`src/client/store.ts` 的 `ViewRoute` 另有 `search` 与 `reader` 两态：它们是 tab 之下的沉浸流，顶部 tab 条不随行；两条返回都固定落书架（书城→详情→阅读这条链也不回书城）。
- 跨 tab 现场是模块级的，切 tab 不丢：书架读面与落架账（`panelShelf`）、书源列表态（`sourceListUi`）、书城选中态（`cityStore`）、任务弹层入口（`requestJobOpen`）、听书播放会话（`ttsPlayer`）各自在场；归属见 `docs/architecture.md` §4 的「浏览器视图内路由与跨卸载现场」与「听书播放层」两行。状态层的任务入口可以切到书源 tab 并直接打开导入弹层或滚到任务卡。
- 面板只做呈现与投影：书架真相、搜索轮次、任务态都在 Node 半；客户端不持任何真相（见 `docs/architecture.md` §3）。
- 滚动条按宿主档主题化：面板自己的两棵树（`.novel-root` 与 `[data-novel-scope]`）的滚动面由 `src/client/styles/shell.ts` 统一成宿主滚动条语义，颜色取 `src/client/styles/tokens.ts` 的 `--novel-scrollbar*`；宿主 DOM 不碰。

## 2. 基础状态

| 状态 | 表达 | 规则 |
| --- | --- | --- |
| 加载中 | 骨架占位 | 书架在 `panelShelf.books === null` 时给骨架；书城在途补骨架卡。骨架不等于空态 |
| 空 | `EmptyState` + 引导动作 | 书架空给导入引导；书城空只认「干净跑完」（`city-view-model.ts` 的 `bookListEmpty`） |
| 失败 | `ErrorBanner` 或场景内联错误 | **不折成空**：书架读失败落「不可用」而不是空架；源清单读失败不落空表；目录未到不摆空目录 |
| 在途 | 按钮禁用 / 进行读条 | 书城换源立即提交；任务卡与体检各自报进度 |
| 不可用 | 入口不渲染 | 没有可渲染的东西时入口直接消失，不造禁用态冒充（`returnDepth` / `hasImportNotes` / `hasMore` 为假即不渲染） |
| 部分失败 | 失败源折叠点名 | 搜索里逐源失败不拖垮整页：失败源进页尾折叠区，点名 code / message / statusDetail |

错误有两条泳道：场景内联走 `src/client/views/bits.tsx` 的 `ErrorBanner`（留在出事的块里，可重试）；全局通知走 `src/client/transient.ts` 的 `pushError` / `pushOk`，由 `src/client/views/NovelStatusOverlay.tsx` 的 `GlobalStatusBar` 呈现——sticky 的错误可带锚点做「定位」，成功提示按 TTL 熄灭。

## 3. 各视图与清单

### 3.1 书架（`src/client/views/ShelfView.tsx`）

- 头：标题、搜索框（关键字只作聚合搜索的跳转输入）、筛选与多选入口。
- 筛选住 `shelf-view-model.ts` 的 `SHELF_FILTERS`：全部 / 在读 / 未读 / 本地；未读 / 在读按进度读数判，不在这里复述。
- 多选是组件态，切 tab 清零；筛选让位给批量条；「全选」只覆盖当前筛选可见；单本 ✕ 与「删除所选」走本文 §4 的确认模态。
- 本地导入在网格末位给引导卡，空架另有兜底卡；导入带持久告警时回执留在本页，没有告警则直接进阅读器。

### 3.2 书城（`src/client/views/CityView.tsx`）

- 左栏：源列表（可搜）；选中源就地展开它自己声明的分类（可搜）。选源选类都立即提交，不攒「开始浏览」。
- 进入判据住 `city-entry.ts` 的 `decideCityEntry` / `resolveCitySelection`：自动那条路做源/分类回落，只问一次，然后提交或跟随。
- 态：在途补骨架；空态只认干净跑完；错误走横幅；无源是独立空态（`cityEmptyState === 'no-sources'`）；续页只认 `round.hasMore` + `loadMore`，尾行给本轮读数。
- 右侧书目是**按源**的，不跨源合并；顺序听源。

### 3.3 书源管理（`src/client/views/SettingsSection.tsx`）

- 组成：待办收件箱（`InboxSection`，可忽略 / 重新显示）、任务槽（`ProbeRunCard`）、源列表（`SettingsSourceList.tsx` 的 `SourceList`）与导入弹层（`SettingsImportPane.tsx` 的 `ImportPane`）。
- 导入：拖放 / 多选文件，另有折叠的粘贴道；提交即关弹层，结果回待办。
- 列表：状态带（总数 / 启用 / 停用 / AI 搜索 / 未验证 / 坏源；AI 搜索计**已标记**数、含停用的预标记——工具面 `eligible` 是「启用 ∧ 文本 ∧ 标记」的候选数，两者不是一个数）、文本 / 状态与 AI / 分组过滤、编辑态批量条（含加入 / 移出 AI 搜索）、七列表格、前端分页（步长是代码常量）。
- 行：状态徽标、「⋯」菜单（验证 / 重验、试跑、登录态、删除）、AI 搜索勾选（方形火花勾）、最右启停开关。AI 勾选只切**工具面**的参与集（与启停正交，停用仍对两种搜索同时生效）；停用源的勾保留但整格灰化、仍可预标记（启用后生效），不另加感叹号或圆点。AI 与启停都是乐观写，失败回滚并在行锚点标红边。
- 删除源走本文 §4 的确认模态；启停与 AI 搜索标记不做二次确认。

### 3.4 搜索（`src/client/views/SearchView.tsx`）

- 入口：书架头搜索框与搜索页表单；`route.keyword` 消费一次即摘除。
- 结果页：进度读数 + 收口摘要（`client/copy/search-summary.ts` 的 `searchSummarySegments`）。
- 空态两分支：没有可搜的源 / 搜了但零命中。
- 默认按书视图（`search-view-model.ts` 的 `deriveRound`，只收 `kept`）：每本一组逐源行，「都加架」三态，回执分三笔（成功 / 仍缺 / 无地址）。
- 逐源详情降级到页尾 `<details>`：组头带状态徽标，suspect 组在组内折叠，失败源折叠并点名错误；无地址的命中渲染为 dead 行。

### 3.5 阅读器（`src/client/views/ReaderView.tsx`）

- 连续滚动，只渲染已载章节。向后的预取判据住 `reader-load.ts` 的 `nextLoadTarget`（哨兵 + 两屏）；向前的保留深度是 `KEEP_BEHIND`，由 `pruneToViewport` 裁。视口顶接近窗口顶时 `checkBackfill` 补上一章，每个视口 episode 的补载次数有上界；窗口与补载的细节住 `client/reader-session.ts` 的头注。
- **阅读方式**（Aa 面板，偏好持久化）：默认连续滚动；切到翻页后按舞台可用宽高、固定像素栏宽与分栏布局（`auto` 宽屏双页 / 窄屏单页，或显式 `single` / `double`）用 CSS 多栏切页（阈值、栏宽换算与点击分区归 `client/reader-pagination.ts` 的 `DOUBLE_PAGE_MIN_WIDTH` / `DOUBLE_PAGE_FORCE_MIN_WIDTH` / `DOUBLE_PAGE_COLUMN_SCALE` / `classifyClickZone`）。栏宽档位（`prefs-ui.ts` 的 `MEASURES`）与字号解耦；滚动与翻页两种阅读方式共用同一套章标题与段间距排版规则，同章内调字号、行距、栏宽或缩放窗口均以当前屏/视口顶段落为锚点重定位，避免内容向回漂移（`ADR-0105`）。点击左右区翻页，中间留给选词、内链与注释；`←` / `→`、PageUp / PageDown、Space、滚轮与触摸横向滑动可翻，阅读浮层打开时键盘让出。末页后翻进下一章开头，首页前翻落上一章末页；跨章落位后按实际页位写进度，并静默预取下一章。三种动效（拟真翻书 / 顺滑平移 / 极速直切）尊重 `prefers-reduced-motion`；页脚给页码与上一页 / 下一页。章内锚点在翻页模式下不精确落位（同章保持当前页、跨章落章首），需要精确锚点用滚动模式。
- 章名展示：顶条当前章名、章首分隔标题、目录与听书章节下拉对空串 / 纯空白统一回退「第 N 章」（判据 `shared/chapter-text.ts` 的 `chapterTitleOrFallback`，客户端文案键 `reader.chapterFallback`）；补充文档叶项没有章号，空标签回退所属分组标题。抓取期数据不改写。
- 滚动补偿归会话：裁章与前插在 `pendingScrollFixes` 记账，`afterRender` 按参考章新旧起点差补 `scrollTop`；浏览器的原生锚定在阅读器子树整棵关掉（`styles/reader.ts`），否则会补两遍。
- 进度：`ReaderSession` 的 `commit` 把恢复 / 跳转 / 滚动防抖统一落到 `saveProgress`；恢复不写，跳转与跨章立落。
- 阅读位置按**顶条下方第一行**算：顶条是 sticky 覆盖层，贴住视口顶后盖住内容最上面约 48px。`ReaderView` 把顶条实测高作为 `topInset` 交给会话，存（`locateChapter` 吃 `scrollTop + inset`）与取（恢复 / 目录与内链跳转 / 排版复位 / 返回原处落位减掉 inset）用同一个值；阅读探针（「从阅读位置起播」）同一口径。视口顶落进章块之间的空档时，进度存储、正文节点锚点与起播探针三条路一致归**下一章**（空档不许答成上一章的尾巴，`ADR-0106`）。只给恢复让位、不给读数让位，每进一次阅读器位置就多漂一条条高——听书恢复的段首正是被顶条挡住的那一行。
- 浮层住 `reader-surfaces.ts` 的 `ReaderSurface`：偏好 / 目录 / 导出 / 补充正文 / 导入注释，**至多一角**；只有偏好与导出带遮罩，Esc 归属见本文 §4。目录抽屉支持即时搜索过滤（保留匹配章节的祖先卷组）与一键定位当前章；导出面板支持整本 / 当前章起 / 仅当前章三档范围预设。导入注释列的是服务端持久化的每一条痕：哪一页读不出正文、哪一条目录被剪、哪一处图片没带进来；每条只说「哪一格、丢了什么、多少处」，面板不补发请求。
- 偏好面板（`PrefsPanel.tsx`）：字号 / 行距滑杆 / 栏宽分段 / 纸张色（含米黄、纯白、淡绿、淡粉、夜间五款命名预设与实时对比度提示的 HSL/Hex 自定义取色器；自定义色独立持久，不随预设切换覆盖）、阅读方式、翻页分栏布局（自动 / 单页 / 双页）与翻页动效、强制深色开关及恢复默认设置；档位住 `prefs-ui.ts`，点遮罩或关闭钮收场。
- **摸鱼模式·舞台骨架**（`MoyuStage.tsx`）：Aa 面板第三档，按宿主会话界面拼台面而不画宿主左栏。会话头 76px 两行：面包屑两段链「{书名} / {会话标题}」（父子两段形态，父段点击回书架）+ 视图标签（对话 / 轨迹、88px 截断 + tooltip）与 ⋯ 工具钮；右角是「打开侧边栏」面板钮（坞展开时整个右角消失）。正文列 `clamp(680px, 64%, 920px)`、28px 圆角输入卡与底部统计坞；右侧文件坞**宽可拖**（min 300、初始 320、8px 分隔条 col-resize + ←/→/Home/End、宽度落 localStorage），窄屏变覆盖抽屉。`Alt+M` 往返 `lastNormalMode`；内部滚动不写进度，切章走 `requestJump`；设置 / 导出 / 导入说明仍由 `ReaderScene` 持有并只渲染一次，摸鱼时换成宿主色浮层（316px popover / 居中说明卡）。
- **摸鱼模式·对话流**：每章是一轮对话——用户气泡（读取 `chapters/NNNN_章节.ts` 的指令）+ 常显的时刻与复制（时刻来自假时钟）；过程组（收起＝动词短语连缀、运行＝「正在读取文件 · 路径」）内含思考 / 读取行：读取行摘要是指路径的 fileLink（点击＝开该文件的文档预览 tab），整行点击展开结果卡。轮头按结局分「处理失败 / 已停止 / 已完成，用时 X分X秒」（进位口径）；错误行第三列是 `<code>` 错误码芯片（NETWORK / PARSE / AUTH / QUOTA / INTERNAL 按真实错误原因映射）。轮尾动作＝复制 / 分支 + 用量胶囊与消息时刻（用量胶囊 + 消息时刻的尾注簇）。呈现风格三档——DSH 对话流（每五段插一条过程行）、紧凑日志流（次要段落 13/20 小字带动作标记）、纯净文档（每四段插阶段标题与 `seg_NN` 标记）；输出节奏两档（流式揭示按码点推进 / 即时直出）。EPUB 插图默认折成资源附件条，点击原地展开。
- **摸鱼模式·假时钟与统计**：屏上时刻只出**假时间线**（首轮当天 09:30、每轮＝上轮时刻＋真实阅读间隔、跨日才带日期；绝不用墙钟直出时刻）。统计坞三件套：ActivityPill（`{turns} 轮 {steps} 步 · {tps} tok/s`，gauge 图标）+ UsagePill（`~N tok · 缓存命中 N%`，database 图标）+ ContextMeter（264px 明细面板：`~N tok / M tok`、分段条、三行图例，触发器 200ms tooltip）——读数全是带 `~` 的自洽估算（tok＝字数×~0.65、缓存％按章序 45%→75%、吞吐＝tok÷揭示真实耗时）。
- **摸鱼模式·输入面（进章入口）**：草稿自增行（多行封顶内滚）；`/` 指令菜单（上下章 / 定位 / 切换呈现与节奏 / 听书 / 返回阅读）、`@` 章节引用（选定真跳章）、模型 chip 两级菜单（「模型」＝呈现风格三档、「推理等级」＝输出节奏两档，点选真改偏好）、＋＝命令菜单；placeholder 照宿主原文。控制行左侧是**工作区入口**（宿主 `.select` 形态、缺省文案「选择工作区」，选择持久化到 localStorage；点一个工作区＝在宿主开/切会话并带到前台，成功与失败各留一条 Toast）；右侧是模型 chip 与发送钮。发送钮两态：流式＝停止方块；其余＝进下一章。空草稿发送钮灰态、Enter 空输入仍进章；有草稿＝草稿落成本轮用户气泡再进章。输入框**不代发宿主任务**：没有附件行、没有队列消息、没有撤销与停止任务。
- **摸鱼模式·工作区入口**：点工作区＝经 `uiWorkspace.openWorkspace` 建/复用该工作区的空白会话并带到前台，随后由用户在宿主界面里使用；插件不投递、不排队、不撤销任何一轮（`ADR-0108`）。打开失败只留一条 Toast（宿主原文），不改阅读现场；工作区面或打开面缺席＝chip 隐藏。入口会话的真轮次按「真轮次镜像」只读进对话流（按入口时那本书归因）；换工作区＝旧镜像清场、旧引用释放。
- **摸鱼模式·真轮次镜像**：宿主真会话的轮次渲染进同一条对话流，与章轮次（假数据）**按真实进入时刻交错**（镜像轮＝用户行的宿主真时刻、章轮次＝该轮进入舞台的时刻，同一时刻章轮在前），镜像轮与章轮共用同一套舞台组件、不加「这是真的」标记。节点映射到舞台已有形态：用户气泡（真 prompt 文本）← `user` / `steering`；思考行（真 reasoning）← `assistant-step` 的 reasoning 块；工具行（真工具名 · 摘要，照 ToolRow 形态）← `tool-call` 节点（根调用 + 子调用按派发序摊平，在跑的带流光）；助手正文（真文本）← `assistant-step` 的 text 块；轮尾（**真时刻 + 真用量**）← `turn-tail`（镜像轮走真值，不走假时钟；用量取宿主真计账 `totalTokens`，不带 `~`、计账不全就只出真时刻）；错误行（「本轮运行失败」+ 真失败消息 + 错误码 `<code>` 芯片，档位沿 `client/moyu-metrics.ts` 的 `errorCodeOf` 映射：有 code 就用、判不出 INTERNAL）← `turn-error`。降级三档：未映射的节点种类（`turn-process` / `compaction` / `context` 等）＝中性占位行（宁降勿猜）；认识但形状不对（必填格缺失 / 类型不符）＝**该轮降级**成占位行（失败半径＝那一轮，不炸整条流）；`uiConversation` 缺席 / 会话未 catalog ＝不镜像（舞台只显章轮次）。镜像只覆盖宿主已加载的历史窗，不自动补页；轨迹台账不收镜像轮。
- **摸鱼模式·文件坞**：38px 标签条＝「文件」tab + 文档预览 tab chips（min/max 80/170、超长渐隐、每枚自带 ×：预览 ×＝关该 tab 回「文件」、「文件」×＝收起文件坞）→ ＋（新开 README.md 预览 tab，已开则聚焦）→ 全屏切换 → 收起面板图标；38px 文件头＝PathLabel 根路径 + 重新读取 / 搜索 / 在应用中打开（＝在正常阅读视图打开当前章）。搜索条带「搜索设置」（范围真切换）与显示 / 隐藏已读章眼睛钮、命中 `<mark>` 高亮与计数行。目录树：根层目录优先、文件夹可开合、当前章自动跟随、已访问降调点（4px + aria 描述）。**文档预览 tab**：README 走真 Markdown 渲染（排版照宿主 Markdown 排版口径）、章节预览显示真章文本；预览内「在阅读器打开」＝在正常阅读视图打开该章。
- **摸鱼模式·轨迹台账**：工具栏只留「展开 / 收起所有轮次」+「搜索轨迹」（按章名真过滤）；sticky 44px 轮次头（`第 N 轮` + 输入 / 输出 / 思考 / 时间四列指标头）+ 30px 事件行（类型标签 用户 / 工具 / 消息 + `#` 序号 + 摘要 + 四列指标，0.5px 发丝 + hover / 选中两态）；点行选中出「事件详情」浮层（概述排版：本章统计＝段数 / 字数 / 揭示耗时 / ~tok +「在阅读器打开」跳章）。指标＝真阅读数据映射（字数→输入 / 输出列、段数→思考列、揭示耗时→时间列）；时间线与拖选不做。
- **摸鱼模式·听书条**：不挂米黄听书条，改在输入框上方显示宿主色 QueueDock 形态（16px 圆角、menu 材质 + 毛玻璃、13px 文、36px 行、行间发丝线、28px 圆钮、预览行 ellipsis）；功能面与阅读器听书条同套（上一段 / 播放暂停 / 下一段 / 语速 / 定时 / 定位到正在念的段 / 设置 / 停止 + 末行整宽章内段滑杆），细节见本文 §3.6。
- 离开一问：`reader-scene.ts` 的 `ReaderScene` 只在书不在架（`onShelf === 'off'`）时问「加入书架」；入架成功才离开，失败只落内联错误、留在阅读器。

### 3.6 听书（`src/client/tts/`）

- **入口与起播**：阅读器顶条的「听书」pill 没有会话时起播——位置取阅读器此刻看得见的那一段（实时探针；量不到才按当前章与书架进度兜底），听书存档只提供音色 / 语速 / 音量与段级续听现场；本书正在听时 pill 是继续 / 暂停，再按不重置位置。pill 的选中态用随纸色现算的跟读字色（条底跟纸，选中色也跟纸；强制深色时回退宿主 brand）。正文选区另浮出「从本段听」：选区判定与浮钮住**阅读器一处**（`src/client/views/listen-from-selection.ts` 的 `useListenFromSelection` + `ReaderView`，document 监听只有一份）。
- **阅读器听书条**（`src/client/tts/TtsBar.tsx`）：只在正在听的会话就是本书时挂载；滚动模式下贴视口底吸底，翻页模式下出流成底部居中浮岛、不挤占书页舞台高度（`ADR-0105`；浮岛收起预览行、窄屏 ≤520px 隐去非空章段读数并保留空章提示，同时翻页页脚 `.novel-book-footer` 就地隐去让位）；条底跟纸走。摸鱼模式不挂这条米黄听书条，改在输入框上方显示宿主色 `QueueDock`：段推进只高亮正文，跨章才按 `requestJump` 同步阅读章节。条上是上一段 / 播放暂停 / 下一段、段读数与当前段一行预览、语速读数（点一次切到下一档，越过 3x 回 0.5x）、定时读数（点一次切到下一档，按 关闭 → 15 → 30 → 60 → 本章结束 → 关闭 循环）、定位到正在念的段、设置与停止；末行整宽是章内段滑杆（拖到任意段即起播，空章不渲染）。语速与定时在条上直接改，不打开设置卡；设置钮是打开完整设置卡的唯一入口。本章没有可朗读段落时段读数是「本章没有可朗读的段落」。
- **设置面板**：在条上方展开，行序为语速、音量、音色（源没有音色表时整行不渲染；浏览器直出按 `voiceURI` 去重、名字后挂语区，平台零音色时不出现、`voiceschanged` 迟到时补上）、定时（关闭 / 15 / 30 / 60 分 / 本章结束）、引擎（当前值不在清单里时仍摆现值；换引擎时音色回退为该源缺省，音色 id 不跨引擎互通；换到直出源先等平台语音表，等不到才报错、选择不生效）、起播章、动作（从阅读位置起播 / 上一章 / 下一章）与一句「听书与阅读共用进度；音色、语速与音量按书记住」。**语速滑杆上写的始终是用户要的倍率**：引擎自己念到哪儿由回执的补速决定，滑杆不拆成「引擎多少 + 补多少」（`ADR-0081`）。面板无遮罩、非模态，但 Esc / 入场焦点 / Tab 圈 / 关后还焦与模态共用 `views/dialog.tsx` 的 `useDialogContract`。设置钮是唯一打开这张卡的入口，也是开关：再点一次收起，Esc 只收弹层、不连带收起承载它的浮层本体（层序见本文 §4）；条上的语速 / 定时单击循环不经过这张卡，卡里的滑杆与档位作精调。
- **失败提示**：单段失败只跳过，连续失败到阈值才暂停；暂停时在听书条 / 浮窗上留一行提示，错误码经 `client/tts/tts-error.ts` 的 `ttsErrorMessage` 翻成人话，不裸露 `TTS_*`。
- **跟读高亮与视口跟随**（`src/client/views/ChapterBody.tsx`）：本书本章正在听时，命中的正文块换文字色（`--novel-live-ink` 按纸色现算），并在段首框外画一枚 currentColor 小三角；不铺底色、不加竖条、不画段内进度线（`ADR-0076`）。高亮不改布局，注释面板里收掉三角。视口跟随：起播首拍、跨章、回退、拖动滑杆这类显式跳转把目标顶对齐到带顶；同一章的自然推进只在目标成为当前可见的最后一段、且落在带的下半部时翻页，普通段不动。读者手动滚动（滚轮 / 触摸 / 滚动键 / 滚动条拖动）或点目录 / 内链 / 返回原处后跟随让位，按听书条的「定位到正在念的段」重新接上并顶对齐（`ADR-0096`）。翻页模式下同一让位判据覆盖用户主动翻页；播放自然推进时页内自动翻页、跨章自动切章（`ADR-0101`）。带顶扣掉顶条高度，目标不会被标题栏盖住。回阅读器与定位都走同一次按 `[data-pidx]` 段块的精确落位（`ADR-0094` / `ADR-0096`）；阅读器在场时消费位置归阅读会话，播放层只写听书细节（`ADR-0093`）。
- **全局迷你条**（`src/client/tts/TtsMiniBar.tsx` / `TtsMiniPanel.tsx`）：注册在宿主 `shell.overlay`，与状态层同一次 inject、两枚条目。缺省是**身份胶囊**（进度环包播放钮 + 展开钮；身份区只给书名与段号，底边一条章内进度细线）；点身份区展开成**边栏**（顶行身份钮 = 点收起 / 拖移动，正文区整段上屏，运输行回阅读器（落到正在念的段，不写阅读进度） / 上一段 / 播放暂停 / 下一段 / 停止，底行只摆当下有的读数）。收起态与展开态共用块中心；松手时离**可达区**边近的边才贴齐（可达区 = 视口减宿主窗控带那条固定遮挡：拖动、吸附、缺省落位与尺寸上限都不进带里，落在带里的旧位置自动捞回），展开态尺寸可拖边调整，设置弹层里另有小 / 中 / 大三档与复位（`ADR-0100` / `ADR-0080`）。设置卡上方优先展开，下方真的更大才翻过去；两侧都放不下时高度收到那一侧余量、卡内滚动，不探出视口（上方余量从窗控带下沿起算）。位置与尺寸落 localStorage，视口或窗控带读数变化后贴着的边继续贴。
- **在场与快捷键**：在场判据 = 会话在 ∧ 阅读器在场书键集合里没有会话本书（阅读器里听本书时由就地条接管，读另一本时迷你条照常在场）。Space 播放 / 暂停、Shift+←/→ 跳段、Esc 收起，只在没有阅读器子树时装；焦点在浮窗控件上时 Space 归控件；拖动只在身份钮与正文区起手，拖动中整块光标为抓手（grabbing）、与悬停指针区分（胶囊身份钮悬停是 pointer，展开态拖面悬停是 grab）；拖边中整块光标跟随所拖边的 resize 指针，指针滑到中间区域也不变。
- **书架听书徽标**（`src/client/views/ShelfView.tsx` / `src/client/shelf-view-model.ts`）：卡片只有一条进度行（`progress`，阅读与听书共用）；「正在听」只标播放层此刻在放的那一本，暂停即撤下（会话仍在，迷你条还在）。徽标钉在**封面顶左**（出流的角标层，不吃任何一行文字的宽度）：多选态这一角归勾选标记，徽标让位；**封面底左**归出处身份——在线书是来源 chip、本地书是「本地」，两者由 `shelfSourceTag` 的判据互斥、同住一个槽位，因此源名与书名各得整行宽度。多选态只动顶左那一角，底左的出处身份照常在场。

## 4. 浮层与危险动作

- **带遮罩**（`src/client/views/dialog.tsx` 的 `Dialog`）：删书确认（单 / 批）、离开阅读器的入架一问、删源确认（单 / 批）、导入弹层（wide）、书籍详情（drawer）、删朗读引擎确认、朗读引擎编辑（form 档）。
- **不带遮罩**：目录抽屉、阅读注释面板、导入注释面板、书源「⋯」菜单、行内登录、书架导入回执、全局状态层与状态条、听书迷你条，以及听书的两份设置卡（阅读器条内与浮窗弹层；它们复用键盘与焦点契约，不设遮罩）。
- 模态契约（Esc、入场焦点、Tab 圈、关闭后还焦、scrim 与 dialog 标记）只在 `src/client/views/dialog.tsx` 定义一次：带遮罩的浮层共读 `Dialog`，无遮罩的听书设置卡复用 `useDialogContract`。同场多层时 `claimKeyLayer` 按打开顺序仲裁——一次 Esc 与 Tab 圈只归最上面那一层，阅读浮层也到这一处认领（`ADR-0037`）。摸鱼舞台的菜单 / 事件详情 / 文档预览 / 文件搜索与 `ReaderScene` 浮层共用同一层序；舞台本体位于控制器层之上、带遮罩确认模态之下。
- **危险层级**：确认框的主按钮用 `danger solid`（实心红）；行内删除用 `danger`（安静红）；启停这类可逆动作不设确认；导出先过范围面板再发。没有「清缓存」入口——缓存失效靠指纹入名（`ADR-0012`）。

## 5. 插件设置页的运行参数卡

- 挂点：宿主插件详情页的 `plugins.bundle.config` 槽位（按 bundle 包名寻址），由 `src/client/config-page.tsx` 的 `registerConfigPage` 注册；值与写协议走宿主设置面 `ctx.remote.settings` 的 `describe` / `mutate`，缺席时整页不出现。
- 版式是**一张卡、一条列表**：工具条（筛选框 + 分区选择器 + 仅看已改 + 改动计数）贴顶，保存条贴底常驻——贴的是滚动区的**可视底边**（宿主页把底部留白做在滚动容器的内边距里，吸附时按 `watchSavebarPin` 的实量补掉，条下不露列表尾部），中间是五段（搜索 / 阅读与导出 / 存储上限 / 网络 / 听书，`GROUPS`；段名以字典为准）自上而下、段内两列配对。只渲染 volatile 字段，启动期字段（如 `dataDir`）不出现。
- 每行一条框：左边是值，框内右侧是单位、人话回读或预设下拉。说明挂在标签后的问号上（悬浮 / 聚焦才浮出，不占布局）；已覆盖、未保存改动与单项重置各有标记。非法值由页面给出该字段的固定提示并标 `aria-invalid`，草稿原样留在框里。
- 找配置项：搜索框按显示名、说明与字段键名匹配，下拉给出命中的配置项（带分区与当前值），回车跳到并聚焦那一行；分区选择器是同一筛选面的粗筛入口。筛选期间分区一律展开。
- 状态：加载中 / 插件未加载 / 设置面读取失败由本页自绘；写入态（只读 / 保存中 / 保存失败）也自绘，保存失败保留草稿。焦点在本卡内时 `Ctrl/⌘+S` 保存、`Ctrl/⌘+K` 聚焦筛选；焦点在卡外不抢宿主同名键。
- **听书段**：五个标量缺省——默认朗读引擎、默认语速、默认音量、朗读音频缓存上限、朗读预取段数；只在本书没有听书存档时兜底。段末是对象数据管理区，默认收成一行「朗读引擎与订阅」，点开才挂载引擎清单（网络读面）。
- **引擎管理**（`src/client/tts/EngineManager.tsx`）：以源清单为骨架、订阅投影按 id 补细节；注册表有而源清单漏报的订阅补成不可用行（灰显，仍可编辑 / 删除）。首读失败（含注册表损坏）只给错误与重试，绝不渲染成 0 源空列表；刷新失败时错误横幅与已就绪的旧清单共存。内置与浏览器行不挂写入口；订阅行带编辑 / 删除；宿主语音服务不在清单时合成一条灰显行，**文案按健康读数分叉**：未安装指路安装语音合成服务插件（点名到哪款住文案与 README，规格不复述名字）、在场未就绪点名原因码并指路到该插件配好供应商，行首徽标分别是「未检测到」与「未就绪」。只读部署下订阅写口一并禁用，清单与导出照常可用。
- **引擎编辑抽屉**（`src/client/tts/EngineEditDialog.tsx`）：520px 表单档模态（比 400px 确认框宽、比 680px 宽档窄；输入框不拉成长条），按「基本信息 / 高级选项 / 登录态」三组组织。表单滚动区预留滚动条槽位并留右缘呼吸，展开组时输入框不贴滚动条。名称与接口地址常显；接口地址是多行 textarea（legado 规则常带换行与超长选项串，单行 input 会把换行吞掉）。内容类型 / 静态请求头 / JS 库收进默认收起的高级组，组标题报「已填 N 项」或「未设置」，组内每格带一句说明（留空语义、密钥会随导出保留等）。登录态三格与「清除」收进默认收起的组，组标题直接报「已配置 / 未配置」，勾上清除后改报「保存后清除」。展开任何一组都在同一个滚动容器里，动作行固定在抽屉底部；保存失败留在组内可重试。
- **订阅导入 / 导出**：粘贴 JSON 或从 URL 导入，回执按条留痕（新增 / 更新计数 + 失败项按下标点名并附原因，坏条只剪自己）。粘贴路径命中原有 id 时提交前确认覆盖几条、会替换哪几格静态数据；URL 路径的回执出现「更新」时补一句「按 id 整条覆盖」。登录态只在编辑抽屉的折叠组里（见上一条），列表与导出只显示「已配置 / 未配置」；导出是公共投影，不含登录态，订阅自带的 `header` 等文本位原样在内。
- 保存即写活配置，下一次读数生效，不重载插件；volatile 更新事件只在 Node 端留痕。

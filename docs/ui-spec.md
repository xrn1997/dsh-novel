# 界面规格（现行）

结构与层级以本文为准；像素值、断点、文案键的唯一定义在 `src/client/` 与 `tests/client/`，本文不抄读数。历史取舍在 git 与 `docs/adr/`，这里只写现在长什么样。架构形状与主人清单见 `docs/architecture.md`。

## 1. 入口与面板

- 槽位注册与三处入口见 `docs/architecture.md` §3；本节只说面板内的 tab 与跨 tab 现场。运行参数走插件详情页的配置卡（本文 §5）。
- 三个 tab 住 `src/client/views/NovelView.tsx` 的 `TABS`：**书架** / **书城** / **书源管理**，切换走 `navigate`。`src/client/store.ts` 的 `ViewRoute` 另有 `search` 与 `reader` 两态：它们是 tab 之下的沉浸流，顶部 tab 条不随行，返回即回原 tab。
- 跨 tab 现场是模块级的，切 tab 不丢：书架读面与落架账（`panelShelf`）、书源列表态（`sourceListUi`）、书城选中态（`cityStore`）、任务弹层入口（`requestJobOpen`）、听书播放会话（`ttsPlayer`）各自在场；它们的归属住在 `docs/architecture.md` §4 的「浏览器视图内路由与跨卸载现场」与「听书播放层」两行，本节只说界面行为。状态层的任务入口可以切到书源 tab 并直接打开导入弹层或滚到任务卡。
- 面板只做呈现与投影：书架真相、搜索轮次、任务态都在 Node 半；客户端不持任何真相（见 `docs/architecture.md` §3）。
- 滚动条按宿主档主题化：面板自己的两棵树（`.novel-root` 与 `[data-novel-scope]`，含各自全部后代）的滚动面由 `src/client/styles/shell.ts` 统一定成宿主滚动条语义，三档颜色取 `src/client/styles/tokens.ts` 的 `--novel-scrollbar` / `--novel-scrollbar-track` / `--novel-scrollbar-hover`——浏览器默认灰条是光暗两态里唯一不跟主题的一块；作用域只到这两棵树，宿主 DOM 一律不碰。

## 2. 基础状态

| 状态 | 表达 | 规则 |
| --- | --- | --- |
| 加载中 | 骨架占位 | 书架在 `panelShelf.books === null` 时给骨架；书城在途补骨架卡。骨架不等于空态 |
| 空 | `EmptyState` + 引导动作 | 书架空给导入引导；书城空只认「干净跑完」（`city-view-model.ts` 的 `bookListEmpty`） |
| 失败 | `ErrorBanner` 或场景内联错误 | **不折成空**：书架读失败落「不可用」而不是空架（`shelf.unavailable` + 内联失败行）；源清单读失败不落空表；目录未到不摆空目录 |
| 在途 | 按钮禁用 / 进行读条 | 书城换源立即提交；任务卡与体检各自报进度 |
| 不可用 | 入口不渲染 | 没有可渲染的东西时入口直接消失，不造禁用态冒充（`returnDepth` / `hasImportNotes` / `hasMore` 为假即不渲染） |
| 部分失败 | 失败源折叠点名 | 搜索里逐源失败不拖垮整页：失败源进页尾折叠区，点名 code / message / statusDetail |

错误有两条泳道：场景内联（`novel-err` 类，留在出事的块里，可重试）与全局通知（`src/client/transient.ts` 的 `pushError` / `pushOk`，sticky 的错误可带锚点做「定位」，成功提示按 TTL 熄灭）。两泳道都由 `src/client/views/bits.tsx` 的共用件承载。

## 3. 各视图与清单

### 3.1 书架（`src/client/views/ShelfView.tsx`）

- 头：标题、搜索框（关键字只作聚合搜索的跳转输入）、筛选与多选入口。
- 筛选住 `shelf-view-model.ts` 的 `SHELF_FILTERS`：全部 / 在读 / 未读 / 本地。
- 多选是组件态，切 tab 清零；筛选让位给批量条；「全选」只覆盖当前筛选可见；单本 ✕ 与「删除所选」都开确认模态。
- 未读 / 在读的判定依据进度读数，不在这里复述。

### 3.2 书城（`src/client/views/CityView.tsx`）

- 左栏：源列表（可搜）；选中源就地展开它自己声明的分类（可搜）。选源选类都立即提交，不攒「开始浏览」。
- 进入判据住 `city-entry.ts` 的 `decideCityEntry` / `resolveCitySelection`：自动那条路做源/分类回落，只问一次，然后提交或跟随。
- 态：在途补骨架；空态只认干净跑完；错误走横幅；无源是独立空态（`cityEmptyState === 'no-sources'`）；续页只认 `round.hasMore` + `loadMore`，尾行给本轮读数。
- 右侧书目是**按源**的，不跨源合并；顺序听源。

### 3.3 书源管理（`src/client/views/SettingsSection.tsx`）

- 组成：待办收件箱（`InboxSection`，可忽略 / 重新显示）、任务槽（`ProbeRunCard`）、源列表（`SettingsSourceList.tsx` 的 `SourceList`）与导入弹层（`SettingsImportPane.tsx` 的 `ImportPane`）。
- 导入：拖放 / 多选文件，另有折叠的粘贴道；提交即关弹层，结果回待办。
- 列表：状态带、文本 / 状态 / 分组过滤、编辑态批量条、六列表格、前端分页（步长是代码里的常量，尾钮按它追加）。
- 行：状态徽标、验证 / 重验、试跑下钻（`ProbePane`，带状态徽标与错误横幅）、「⋯」菜单、最右 `role=switch` 启停。启停是乐观写，失败回滚并在行锚点标红边。
- 删除源走确认模态；启停不做二次确认。

### 3.4 搜索（`src/client/views/SearchView.tsx`）

- 入口：书架头搜索框（带关键字跳转）与搜索页表单；`route.keyword` 消费一次即摘除。
- 结果页：进度读数 + 收口摘要（`client/copy/search-summary.ts` 的 `searchSummarySegments`）。
- 空态两分支：没有可搜的源 / 搜了但零命中。
- 默认按书视图（`search-view-model.ts` 的 `deriveRound`，只收 `kept`）：每本一组逐源行，「都加架」三态，回执分三笔（成功 / 仍缺 / 无地址）。
- 逐源详情降级到页尾 `<details>`：组头带状态徽标，suspect 组在组内折叠，失败源折叠并点名错误；无地址的命中渲染为 dead 行，不给可点入口。

### 3.5 阅读器（`src/client/views/ReaderView.tsx`）

- 连续滚动，只渲染已载章节。窗口两端的规则各一条：向后由预取判据决定（住 `reader-load.ts` 的 `nextLoadTarget`，哨兵 + 两屏，`ReaderSession` 的 `checkPreload` 起货）；向前的保留深度是 `KEEP_BEHIND`（视口之前留几章，`pruneToViewport` 按它裁）。裁的是「视口章所属的连续区间 ∩ 保留深度」——不裁则连续前读时 DOM 只增不减，锚点测量随会话线性变贵。
- 回溯阅读不因裁章失效：视口顶接近已载窗口顶（`BACKFILL_SCREENS` 屏以内）时 `checkBackfill` 补上一章，走的是同一个单在途槽。补载只在真实视口读数到过一次之后判断；存档恢复（含章内比例 0）在双帧落位完成前由 `restoring` 一闸挡住预取、位置提交与补载（此前的 `scrollTop` 还是进入前的旧值）——比例 0 也落位到存档章顶，否则回溯补载的前插会把视口带进上一章；前插补偿按「原来第一章的新旧起点差」算（章间外边距计入），阅读位置不随补载漂移。补载还要求实测章高 > 0、不越过 `pruneToViewport` 的裁章下界（否则新章落地即被裁掉、触发同一章重取），且每个视口 episode 的自动补载次数有硬上界（`BACKFILL_MAX_CHAPTERS`，跳章与跨章换位重置）。
- 滚动补偿**归会话，不归浏览器**：`overflow-anchor: none` 盖住阅读器整棵子树（`styles/reader.ts`），因为滚动容器是祖先 `.novel-main`、而该属性不继承——只写正文容器挡不住章块自己当选锚点。浏览器再自动锚一次就是双重补偿，所以裁掉视口上方的章、往窗口顶前插一章这两件事都由 `pendingScrollFixes` 记账，在 `afterRender`（DOM 已提交）按参考章新旧起点差补 `scrollTop`（参考章量不到时分别退回高度和 / 新章块高）；导航跳章清空这笔账，落位归 `settleJump`。子树里自带头尾的内嵌浮层（目录抽屉、注释面板）因此也不带原生锚定——它们靠自己的开合，不靠内容位移补偿。
- 进度：`ReaderSession` 的 `commit` 四个来源——恢复不写、跳转与跨章立落、滚动防抖——统一落到 `saveProgress`。
- 浮层住 `reader-surfaces.ts` 的 `ReaderSurface`：偏好 / 目录 / 导出 / 补充正文 / 导入注释，**至多一角**；`openSurface` / `closeAll` 管开合，只有偏好与导出带遮罩，Esc 归属由 `escOwner` 判（模态优先）。导入注释列的是服务端持久化的每一条痕：哪一页读不出正文（它仍在目录里，点开是空白页）、哪一条目录被剪、哪一处图片没带进来；每条只说「哪一格、丢了什么、多少处」——半径与严重度留在服务端不外泄（`LocalImportWarning` 只有 `code` / `resource` / `message`），面板也不补发请求。
- 离开一问：`reader-scene.ts` 的 `ReaderScene` 只在书不在架（`onShelf === 'off'`）时问「加入书架」；入架成功才离开，失败只落内联错误、留在阅读器。

### 3.6 听书（`src/client/tts/`）

- **入口**：阅读器顶条的「听书」pill。没有会话时起播——位置取阅读器此刻看得见的那一段（实时探针；量不到才退当前章首段），听书存档只提供音色 / 语速 / 音量与段级续听现场；本书正在听时 pill 是继续 / 暂停，再按不重置位置。正文选区另浮出「从本段听」按钮：选区判定与浮钮住**阅读器一处**（`src/client/views/listen-from-selection.ts` 的 `useListenFromSelection` + `ReaderView`，document 监听只有一份、不随已载章数长）；注释面板不在阅读器正文容器里，天然没有选区入口。
- **阅读器听书条**（`src/client/tts/TtsBar.tsx`）：只在**正在听的会话就是本书**时挂载；条贴视口底、条底跟纸走（控制器强制深色时让回宿主暗底）。条上是上一段 / 播放暂停 / 下一段、段读数（第 n / 总段数）与当前段一行预览、语速与定时两个读数 chip（定时读数与浮窗同一份：计时中显倒计时、否则显档位）、**定位到正在念的段**、设置与停止；末行整宽是**章内段滑杆**（拖到任意段即起播，空章不渲染）——条上只有这一条进度，段内时间滑杆与段内 seek 不在界面出现（`ADR-0075`）；滑杆与浮窗的章内进度条吃**同一个 value 的两种控件形态**（同一算式：条上取整到段粒度、浮窗连续填充）。本章没有可朗读段落时段读数是「本章没有可朗读的段落」。
- **听书设置面板**：在条上方展开（同一浮层卡片族；头行左侧是可见卡名「听书设置」、右侧是关闭钮，卡名同时是 dialog 的无障碍名），行序为语速、音色（源没有音色列表时整行不渲染；浏览器直出用平台音色并按 `voiceURI` 去重、名字后面挂语区——几十支跨语种的音色只给名字就是让用户盲选；平台零音色时行不出现，真表随 `voiceschanged` 迟到时这一行随事件补上——不等同一次重渲染）、音量、定时（关闭 / 15 / 30 / 60 分 / 本章结束）、引擎（源清单；当前值不在清单里时仍把现值摆出来，不静默换源；换引擎时音色回退为该源缺省，音色 id 不跨引擎互通；换到「这台设备开不了口」的直出源先**等平台的语音表**（Chromium 冷启动首读常是空表、真表随 `voiceschanged` 迟到，等待上限住 `client/tts/player.ts` 的 `DIRECT_VOICES_WAIT_MS`），等不到才报错、选择不生效，不放着一个必坏的源逐段失败）、**起播章**（全章清单，换选即换章并从首段起播）、动作（从阅读位置起播 / 上一章 / 下一章）与一句「听书与阅读共用进度；音色、语速与音量按书记住」。面板无遮罩、非模态，但 Esc / 入场焦点 / Tab 圈 / 关后还焦与模态共用 `views/dialog.tsx` 的 `useDialogContract`。设置入口是**开关**：触发钮（齿轮，语速 / 定时这类读数入口同理）再点一次收起弹层，开着时齿轮亮 brand；弹层在场时按 Esc 只收弹层，不连带收起承载它的浮层本体。
- **播放失败提示**：单段失败只跳过，连续失败到阈值才暂停；暂停时在听书条 / 浮窗上留一行提示，错误码翻成人话、不裸露 `TTS_*`（码→人话的唯一一道口是 `client/tts/tts-error.ts` 的 `ttsErrorMessage`，起播与换源共用）。阈值是代码常量、提示文案住 `src/client/copy/tts.ts`，本文不抄读数。
- **跟读高亮**（`src/client/views/ChapterBody.tsx`）：本书本章正在听时，命中的正文块换文字色（`--novel-live-ink` 由纸色现算：暖赭带里离正文墨色最远、与纸面对比度不低于 5.5:1 的一档，跟着纸色换；文字章逐行、图文章与表格按块，命中判据与「从本段听」同一条起段号口径），并在段首框外画一枚 `currentColor` 小三角——纯换色在部分纸色下只是「稍亮/稍暗一点」，字形标记不靠色彩差说话（`ADR-0076`）；仍不铺底色、不加左竖条、不画段内进度线。**只标记、不滚动**：自动跟随会经阅读会话的滚动防抖改写视口位置，与播放层自己的落盘节拍互相覆盖（`ADR-0071`）；要把视野带过去按听书条的「定位到正在念的段」，那是一次显式导航：目标章在已载窗口内就直接滚到那一段，不在就先跳到那一章，载入后居中正在念的段。高亮不改布局（相对定位 + 框外伪元素），进出不动几何、不触发滚动补偿；注释面板里的复用场景收掉三角、不留半标记。
- **全局迷你条**（`src/client/tts/TtsMiniBar.tsx` / `src/client/tts/TtsMiniPanel.tsx`）：注册在宿主 `shell.overlay`，与状态层同一次 inject、两枚条目；order 排在状态层之前（迷你条 90、状态层 100）。**两个完整形态**（`ADR-0073`；内容层级按 `ADR-0079`——封面退场，书名只做身份）：缺省是**身份胶囊**（两颗并列真按钮：进度环包播放钮 + 盖住身份区的展开钮；身份区只给书名与段号（书名贴左、段号贴右——胶囊是固定宽，两端都要有落点，右侧不留空档），底边一条章内进度细线，不再显示半截句子）；点身份区为**展开边栏**：顶行（身份钮 = 点收起 / 拖移动，与齿轮并列，行尾 ▽ 是身份钮内的可见提示）、正文区（当前段整段上屏、吃剩余高度，装不下时尾行右下角挂「看全文」回阅读器并定位到本段；正文区可拖不可点）、运输行（回阅读器 / 上一段 / 播放暂停 / 下一段 / 停止，颗颗 ≥32）、底行读数（语速 / 段号 / 章内进度条 / 定时倒计时；空章与无其它读数时底行整行不渲染）。展开态尺寸可由用户调整：拖左 / 右 / 下三条边与右下角，对边锚定，范围与缺省归 `ADR-0080`；设置弹层里有「小 / 中 / 大」三档与复位，只投影给浮窗那一份设置卡；尺寸在现场只记意图，呈现时夹取、夹取不回写。没有 idle 半隐、没有同一胶囊藏一半的 hover 抽屉；收起态自身完整可读可播。位置自由落位：两个形态共用同一个块中心，拖动两轴跟手，松手时离视口边 ≤ 24px 的那条边才贴齐（两轴独立，可落在边角），其余停在原地；方向键四向移动（Shift 三档）、Home 回缺省位置；浮窗定位由布局读数一次给全（`src/client/tts/mini-bar-state.ts` 的 `miniBarLayout`，缺省轴——横向贴右缘、纵向居中——也在读数里解析成落位值），样式层不再有缺省定位；两个派生读数各管一件事——`data-side` 由中心算出，只管设置弹层往哪边开；`data-flush` 由块边缘与视口边算出，只管贴边形态（收掉靠屏幕那一条边框、把那两侧改成直角），块悬在屏内时它是 `none`，展开态就是完整的一块（四条边都有描边、四角同圆）。位置、尺寸与收起态落 localStorage，视口变化后贴着的边继续贴、自由位置只夹不漂，换形态按新尺寸重夹。设置面板与阅读器条共读同一份行清单（`TtsSettings.tsx`：语速 / 音色 / 音量 / 定时 / 引擎 / 起播章；浮窗多一行尺寸三档），设置弹层从边栏上方或下方展开——上方留不下一整张卡片（内容实测高与 `max-height: 60vh` 取小）就翻到下方，这一判据跟着现场走：弹层开着再拖动、键盘挪块或缩窗口都会重算，不留旧方向把弹层甩出屏外；左缘镜像。设置是**开关**（口径见上条「听书设置面板」）：齿轮与语速 / 定时两个入口 chip 再点一次收起弹层、浮窗本体不收；开着时齿轮亮 brand；弹层在场时按 Esc 只收弹层，不连带收起承载它的浮窗本体。底色读宿主**浮层**语义（浮动钮同底），**不跟阅读器的纸色走**。在场判据（`ADR-0072`）：会话在 ∧ 阅读器在场书键集合里没有会话本书——阅读器里听本书时就地条接管，阅读器开着**另一本**时迷你条照常在场；判据读 `reader-presence` 的子树信号与书键，**不看插件内路由**（`ADR-0022`：中央呈现座位一切走就卸载面板子树）。快捷键（Space 播放/暂停、Shift+←/→ 跳段、Esc 收起）只在没有阅读器子树时装：阅读器在场时 Space 归滚动、Shift+方向键归选区、Esc 归浮层契约。焦点落在浮窗自己的控件（两个身份钮、输入件）上时 Space 归那颗控件——快捷键不替用户按手上那颗钮；指针拖动只在指定拖面（两个身份钮与展开态正文区）起手，其余控件不起拖、不 resize。Esc 同场多层时只收最上面那一层（层序住址见本文 §4 与 `views/dialog.tsx`）。进度不撒谎：环、胶囊底边细线与章内进度条的段内比例只读字节型计时介质，直出型环退化为静态轨道、进度条只按段号推进；收起态与边栏不直接写阅读进度——位置落盘归播放层的节拍：暂停 / 停止 / 关页 / 起播另一本走立即 flush（定时到点走的也是暂停那条路），跳段、跳章与段间推进只排 2s 防抖。「回阅读器」记一次性重定位现场（带书键）并切回阅读器，恢复走 restore、不写阅读进度。
- **书架听书徽标**（`src/client/views/ShelfView.tsx` / `src/client/shelf-view-model.ts`）：卡片只有一条进度行（`progress`，阅读与听书共用；听书落盘也会推进它），不再摆「听至」第二行；「正在听」只标播放层**此刻在放**的那一本，暂停即撤下（会话仍在，迷你条还在）。

## 4. 浮层与危险动作

- **带遮罩**（`src/client/views/dialog.tsx` 的 `Dialog`）：删书确认（单 / 批）、离开阅读器的入架一问、删源确认（单 / 批）、导入弹层（wide）、书籍详情（drawer）、删朗读引擎确认、朗读引擎编辑。
- **不带遮罩**：目录抽屉、阅读注释面板、导入注释面板、书源「⋯」菜单、行内登录、书架导入回执、全局状态层与状态条、听书迷你条。
- 模态契约（Esc、入场焦点、Tab 圈、关闭后还焦、scrim 与 dialog 标记）只在 `src/client/views/dialog.tsx` 定义一次：带遮罩的浮层共读 `Dialog`，键盘与焦点那一半（`useDialogContract`）另给阅读器内无遮罩的听书设置卡复用。同场多层时 `claimKeyLayer` 按打开顺序仲裁——一次 Esc 与 Tab 圈只归最上面那一层，阅读浮层那一家也到这一处认领（裁决见 `ADR-0037`）。
- **危险层级**：确认框的主按钮用 `danger solid`（实心红）；行内删除用 `danger`（安静红）；启停这类可逆动作不设确认；导出先过范围面板再发。当前没有「清缓存」这类入口——缓存失效靠指纹入名，不提供删除式清理（`ADR-0012`）。

## 5. 插件设置页的运行参数卡

- 挂点：宿主插件详情页的 `plugins.bundle.config` 槽位（按 bundle 包名寻址的 keyed 子槽位），由 `src/client/config-page.tsx` 的 `registerConfigPage` 注册。
- 版式是**一张卡、一条列表**：工具条（筛选框 + 右端分区选择器 + 仅看已改 + 改动计数）贴卡片顶边，保存条贴卡片底边（常驻，滚到哪儿都在），中间是五段（搜索 / 阅读 / 存储 / 网络 / 听书，`GROUPS`）自上而下、段内两列配对。只渲染运行时可活更的字段（volatile）——启动期字段（如 `dataDir`）不出现在这里。
- 每行只有一条 30px 的框：左边是值，框内右侧是**单位**（灰）、**人话回读**（蓝，`≈ 15 秒`）或**预设下拉**（回读值 + 箭头）；预设不再铺一排 chip——chip 占一整行高度且预设一多就换行，收进框内下拉后「当前生效值」与「可选档位」是同一个入口，值仍是原始数。说明挂在标签后的**问号**上（悬浮 / 聚焦才浮出，绝对定位、不占布局也不改行高——挂在行下方会把整页往下推一节）；已覆盖是标签后的空心点、未保存改动是实心点、单项重置是标签后的 ↺ 图标。非法值就地报原文并标 `aria-invalid`。前置态（加载中 / 插件未加载 / 设置面读取失败）与写入态（只读 / 保存中 / 保存失败）都由本页自绘；值与写协议走宿主设置面（`ctx.remote.settings` 的 `describe` / `mutate`），草稿与保存态自持，`Ctrl/⌘+S` 保存、`Ctrl/⌘+K` 聚焦筛选。
- **找配置项**：搜索框按**显示名、说明与字段键名**（配置表 / 日志 / 文档里写的 `ttsDefaultRate` 这类）匹配，打字后它的下拉变成**命中的配置项**（带所属分区与当前值），回车跳到并聚焦那一行；分区选择器（右端 `全部 ▾`）是同一个筛选面的粗筛入口，菜单里列分区与各段字段数——分区继续增加时只是菜单变长，工具条宽度不变。筛选期间分区一律展开（收起的段里藏着命中的行等于把结果又藏起来）。
- **听书段**：五个标量缺省——默认朗读引擎、默认语速、默认音量、朗读音频缓存上限、朗读预取段数。它们只在本书没有听书存档时兜底；引擎标识是订阅数据的身份，不是引擎对象本身。段末是对象数据管理区，默认收成一行「朗读引擎与订阅」，点开才挂载引擎清单（引擎清单是网络读面）。
- **引擎管理**（听书组内的对象数据管理区，`src/client/tts/EngineManager.tsx`）：以源清单为骨架、订阅投影按 id 补细节。状态显式分开：加载中给状态行；**首读失败**（含注册表损坏）只给错误与重试，绝不渲染成 0 源的空列表；**刷新失败**时错误横幅与已就绪的旧清单共存——上一次读到的清单仍是可读事实，不整块换成错误。就绪列出内置 / 浏览器直出 / 订阅 / 宿主语音服务四类行。内置与浏览器行不挂写入口；订阅行带编辑 / 删除；宿主语音服务缺席时合成一条灰显「未检测到」行，而不是整行消失。只读部署下订阅写口（编辑 / 删除 / 导入）一并禁用，清单与导出是读面，照常可用。
- 引擎订阅的导入（粘贴 JSON / 从 URL）回执按条留痕：新增 / 更新计数 + 失败项逐条按**下标**点名并附原因，坏条只剪自己。**粘贴路径**若读得出 id 且命中现有订阅，提交前先确认并点名会覆盖几条、会替换哪几格静态数据（静态请求头 / JS 库 / 内容类型，本次条目缺这几格等于清空），取消 / 改原文 / 收面板都撤掉这次待确认；解不开的 JSON 交给服务端回执点名。**URL 路径**在服务端才知道清单内容，回执里出现「更新」时补一句「按 id 整条覆盖」的含义说明。登录态那一组只出现在编辑抽屉里（三个文本框 + 盘上已有登录态时的「清除已保存的登录态」勾选）；列表与导出只显示已配置 / 未配置状态位。三个文本框留空表示保留盘上那一份，填写才整组覆盖；勾上清除后文本框禁用，保存会删掉盘上那一组（本次填写不生效）。导出交回的是公共投影：登录态不在其中，订阅自带的 `header` 等文本位原样在内（口径见 `src/shared/wire.ts` 的 `TtsEnginePublic`）。
- 保存即写活配置，下一次读数生效，不重载插件；volatile 更新事件只在 Node 端留痕。
